Interpretability

The Jacobian Lens

An interpretability method that reuses exactly the Jacobian machinery from backprop — but points it at the model's own residual stream instead of a scalar loss, and averages it over ~1,000 prompts to separate a concept's general "disposition to be verbalized" from one prompt's incidental use of it.

This page works out the math behind the Jacobian-lens method from Anthropic's workspace interpretability write-up. It is not a training derivation — nothing here computes a gradient for an optimizer step. It is the same linear-algebra object, the Jacobian, turned around and used to read a trained model instead of to train it: given an intermediate activation on the residual stream, what does the model tend to do with it by the end of the forward pass?

1. The lens Jacobian

Fix one prompt and one pair of positions \(t\le t'\). The single-context lens Jacobian is

\[ J_\ell \;=\; \frac{\partial \mathbf{h}_{\text{final},t'}}{\partial \mathbf{h}_{\ell,t}} \;\in\; \mathbb{R}^{d\times d} \]

This is exactly the object backprop.html §1 defines, \(J=\partial\mathbf{y}/\partial\mathbf{x}\), numerator layout, output rows by input columns. The only thing that changed is the choice of \(\mathbf{y}\) and \(\mathbf{x}\): training backprop fixes \(\mathbf{y}=L\), a scalar loss, and asks for \(\partial L/\partial\theta\) over every parameter. Here \(\mathbf{y}=\mathbf{h}_{\text{final},t'}\), an intermediate activation, and \(\mathbf{x}=\mathbf{h}_{\ell,t}\), a residual-stream vector partway through the network — both are vectors, so the result is a genuine \(d\times d\) matrix, not a gradient vector.

Because layers compose, \(J_\ell\) is also literally a slice of the chain-rule product from backprop.html §2 — the product of every per-layer Jacobian from \(\ell+1\) up to the final layer:

\[ J_\ell = J_L\,J_{L-1}\cdots J_{\ell+1} \]
Backprop never materializes this product — it collapses it into a single vector–Jacobian product against the scalar loss (backprop.html §3), because that's all training needs. Interpretability needs the actual directions, not a gradient, so the Jacobian lens keeps the matrix — but still never forms a dense \(d\times d\) matrix per layer per prompt (that would be backprop.html §1's "materializing is a non-starter" argument, and \(d\) here is a few thousand). In practice it's built from Jacobian–vector products (JVPs, the forward-mode object from backprop.html §4) probed along the handful of directions the method actually needs — chiefly the rows of \(W_U\bar J_\ell\) defined in §4 below.

2. What a single prompt conflates

\(J_\ell\) is a local derivative: its value depends on the exact activations that one prompt produced, because the network is nonlinear. Two prompts that both eventually produce the token "Paris" can have different \(J_\ell\) at the same layer, because the surrounding computation — what else is active, what the model is doing with the concept — differs. A single-prompt Jacobian mixes two things that are conceptually distinct:

  1. the model's general disposition to verbalize a given concept — a stable channel that exists whenever the model is in a position to say it, independent of context;
  2. the particular use the concept is being put to right now — this prompt's local curvature, an artifact of this one context.

Concretely: if a concept has some "true" direction \(\mathbf{w}\) that generically routes toward its token at the final layer, a single prompt's estimate looks like \(\mathbf{w}+\boldsymbol{\eta}\), where \(\boldsymbol{\eta}\) is contextual noise specific to that prompt. There is no way to tell, from one such estimate, how much of it is \(\mathbf{w}\) and how much is \(\boldsymbol{\eta}\).

3. Averaging over prompts and positions

The fix is to average \(J_\ell\) over many contexts, so the shared component survives and the idiosyncratic one cancels:

\[ \bar J_\ell \;=\; \mathbb{E}_{t,\,t'\ge t,\,\text{prompt}}\!\left[\frac{\partial \mathbf{h}_{\text{final},t'}}{\partial \mathbf{h}_{\ell,t}}\right] \]

The expectation runs over the source position \(t\), every later position \(t'\ge t\) within the same context, and a corpus of about one thousand prompts sampled from a pretraining-like distribution — so \(\bar J_\ell\) is not one context's slope but the network's typical local behavior around layer \(\ell\).

This is the same fact optimizers.html §2 writes as \(\hat g_t = \nabla_w L(w_t) + \xi_t\), \(\mathrm{Var}(\xi_t)\propto 1/B\) — a noisy per-example estimate splits into a true shared component plus mean-zero noise whose variance shrinks with the number of samples averaged in. Optimizers.html runs that fact forward: small \(B\) means more noise, and that noise is the point — it's what lets SGD escape saddles and shallow minima. The Jacobian lens runs it in reverse: it wants that noise gone, so it enlarges \(N\) (prompts × positions playing the role of the batch) until only the shared, context-independent direction is left standing.
residual noise, \(1/\sqrt{N}\) \(N\approx 1{,}000\) (paper's corpus)

Averaging is a Monte Carlo estimate, and it converges like one. If each single-prompt \(J_\ell\) is \(\mathbf{w}+\boldsymbol{\eta}\) with \(\mathrm{Var}(\boldsymbol{\eta})=\sigma^2\), the \(N\)-prompt average has noise standard deviation \(\propto 1/\sqrt N\) (purple curve, shown out to \(N=200\) for readability). The paper's actual corpus of \(N\approx 1{,}000\) prompts (dashed reference) pushes that residual down to roughly 3% of a single prompt's — which is exactly why one prompt conflates "general disposition" with "this context's noise," and a thousand prompts mostly resolve them.

4. Reading out tokens: composing with the unembedding

\(\bar J_\ell\mathbf{h}_\ell\) is a first-order simulation of the remaining \(L-\ell\) layers: instead of actually running them, it applies their averaged linear effect to whatever the residual stream currently holds — the "best linear approximation" framing from backprop.html §1, evaluated at a population average rather than one point. Feeding that estimate through the same norm → unembed → softmax pipeline every real forward pass ends with gives a full vocabulary readout of an intermediate activation:

\[ \mathrm{lens}(\mathbf{h}_\ell) \;=\; \mathrm{softmax}\bigl(W_U\,\mathrm{norm}(\bar J_\ell\,\mathbf{h}_\ell)\bigr) \]

Composing \(W_U\) with \(\bar J_\ell\) up front produces one direction per vocabulary token — the J-lens vectors, the rows of \(W_U\bar J_\ell\):

\[ v_k = \bigl(W_U\bar J_\ell\bigr)_{k,:} \;\in\; \mathbb{R}^d \]

\(v_k\) answers a causal question: nudging the residual stream at layer \(\ell\) in direction \(v_k\), how much does that move token \(k\)'s eventual logit, in a typical context? It is the interpretability-side analogue of a linear probe — except its weights come from the model's own averaged derivative, not from fitting a classifier to activations after the fact.

5. Two simpler lenses, for comparison

The J-lens generalizes two earlier, cheaper readouts:

LensWhat it uses for \(\bar J_\ell\)Fit typeWhere it breaks
Logit lens\(\bar J_\ell = I\)No fit — a free simplificationDegrades in early layers, where little has been rotated into anything close to the final vocabulary basis yet
Tuned lensA per-layer affine map fit by regression against real final-layer activationsCorrelational"Skips ahead" — it can predict a token before the model's own remaining layers have actually computed it, since it's fit to correlate with the output, not to reflect a causal derivative
J-lens\(\bar J_\ell = \mathbb{E}[\partial\mathbf{h}_{\text{final}}/\partial\mathbf{h}_\ell]\)Causal, first-order, averaged over ~1,000 promptsStill only linear — misses whatever the remaining layers compute nonlinearly

The logit lens is the special case \(\bar J_\ell=I\) of the formula in §4 — assume the residual stream is already in its final form and just unembed it directly. That is a good approximation late, where pre-norm keeps per-layer updates small (the "clean highway" argument from transformer-block.html), and a bad one early, where it isn't. The tuned lens fixes the early-layer failure by fitting a map instead of assuming identity, but loses the causal reading in the process — its map is trained to match the output, not to be the network's actual derivative, which is exactly the trade the J-lens is designed to avoid: it stays causal by construction, and stays stable by averaging rather than by fitting.

6. Sparse decomposition: which concepts are active

Under the standard superposition hypothesis — more features than dimensions, packed into a roughly-sparse code — an activation is modeled as a small nonnegative combination of J-lens vectors:

\[ \mathbf{h}_\ell \;\approx\; \sum_{i=1}^{k} c_i\, v_{k_i}, \qquad c_i \ge 0 \]

Finding that combination is a sparse-coding search over an enormous, overcomplete dictionary — one candidate direction \(v_k\) per vocabulary token, so \(V\) in the hundreds of thousands against \(d\) in the low thousands. The paper's algorithm, gradient pursuit, is a matching-pursuit variant: at each step it adds the not-yet-used \(v_k\) most aligned with the current residual to the active set, then re-fits all active coefficients with a gradient step rather than freezing earlier picks the way plain matching pursuit would. \(k\) is deliberately loose — the paper calls it "somewhat arbitrary" — but caps it at 25, matching what's empirically seen as the number of meaningful concepts active at a single token position.

With sparsity budget \(k\) fixed, the set of representable activations — the paper's "J-space" — is a union of \(k\)-dimensional cones, one per possible \(k\)-subset \(S\) of the \(V\) J-lens vectors: \(\bigcup_{|S|=k} \mathrm{cone}\{v_i : i\in S\}\). It's the interpretability-side analogue of a dictionary-learning code space, except the dictionary is read directly off \(W_U\bar J_\ell\) rather than learned separately.

7. Steering: turning a direction into an intervention

A J-lens vector is only as trustworthy as its causal effect — the whole point of deriving it from an actual Jacobian rather than a correlational fit is that it should do something when you push on it. Two ways the paper tests that:

Simple steering

Add or subtract a multiple of a J-lens vector directly on the residual stream:

\[ \mathbf{h} \;\leftarrow\; \mathbf{h} + \alpha\, v_k \]

\(\alpha>0\) injects the concept — makes the model more disposed to eventually verbalize token \(k\) downstream; \(\alpha<0\) ablates it. If nudging along \(v_k\) reliably shifts behavior in the predicted direction, that validates \(v_k\) as a real causal handle, not just a readout artifact.

Coordinate swapping

To exchange two concepts \(s\) and \(t\) — e.g. swap "Paris" for "Rome" — rather than blindly adding one direction and subtracting another, project \(\mathbf{h}\) onto the 2-D subspace they span and swap only its coordinates there. Stack \(V=[v_s\ \ v_t]\in\mathbb{R}^{d\times 2}\), let \(V^\dagger\) be its Moore–Penrose pseudoinverse (needed because \(v_s,v_t\) aren't generally orthogonal), and let \(\sigma\) swap a 2-vector's entries:

\[ \mathbf{c} = V^\dagger\mathbf{h} \in \mathbb{R}^2, \qquad \mathbf{h}_{\text{patched}} = \mathbf{h} + V\bigl(\sigma(\mathbf{c}) - \mathbf{c}\bigr) \]

\(\mathbf{c}=[c_s,c_t]\) are \(\mathbf{h}\)'s coordinates along \(v_s\) and \(v_t\); \(Vc = c_s v_s + c_t v_t\) is the part of \(\mathbf{h}\) those two directions already explain, and \(V\sigma(c) = c_t v_s + c_s v_t\) is that same reconstruction with the coefficients exchanged. Adding the difference replaces "how much \(s\)" with "how much \(t\)" and vice versa, while everything orthogonal to \(\mathrm{span}\{v_s,v_t\}\) — the rest of what \(\mathbf{h}\) represents — passes through untouched. It's the same delta-patching idea as simple steering, just confined to a subspace instead of one line.

Implementation, for grounding: 25 evenly spaced layers (reindexed to a 0–100% depth axis), a corpus of ~1,000 pretraining-like prompts, primary model Claude Sonnet 4.5 with key results cross-checked on Haiku 4.5 and Opus 4.5, and the model's own final normalization applied before the unembedding in every readout.

8. Summary

Single-context Jacobian

\(J_\ell=\partial\mathbf{h}_{\text{final},t'}/\partial\mathbf{h}_{\ell,t}\) — same object as backprop's \(J\), pointed at an activation instead of a loss

The conflation

one prompt mixes general disposition with this context's noise

The fix

\(\bar J_\ell=\mathbb{E}_{t,t',\text{prompt}}[J_\ell]\) — noise \(\propto 1/\sqrt N\), same identity as optimizers.html §2, run in reverse

Token readout

\(\mathrm{lens}(\mathbf{h}_\ell)=\mathrm{softmax}(W_U\,\mathrm{norm}(\bar J_\ell\mathbf{h}_\ell))\); J-lens vectors \(=\) rows of \(W_U\bar J_\ell\)

vs. logit / tuned lens

logit lens \(=\) the special case \(\bar J_\ell{=}I\); tuned lens fits correlationally and skips ahead

Sparse decomposition

\(\mathbf{h}_\ell\approx\sum_{i\le k} c_i v_{k_i}\), \(c_i\ge0\), via gradient pursuit, \(k\le25\)

Steering

\(\mathbf{h}\leftarrow\mathbf{h}+\alpha v_k\)

Coordinate swap

\(\mathbf{h}+V(\sigma(V^\dagger\mathbf{h})-V^\dagger\mathbf{h})\)

Built from: the Jacobian and chain-rule machinery of backprop, applied to the residual stream and unembedding of the transformer block, using the same noise-averaging identity as mini-batch gradients in optimizers — pointed at reading a trained model instead of training one.
