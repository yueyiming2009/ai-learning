Linear Attention

Remove the softmax and attention collapses into a fixed-size recurrent state — O(1) memory and compute per decoded token. What you gain, what you lose, and the fixes that led to RetNet, Mamba-2, and Gated DeltaNet.

The Basic Idea

Softmax attention answers every query by scoring it against every key seen so far. That exactness has a price that grows with context length \(T\): the KV cache stores \(O(T)\) vectors, and each decoded token reads all of them — \(O(T)\) memory traffic and FLOPs per token.

Linear attention asks: what if the similarity function were factorizable? If the score between a query and a key is a plain dot product (no softmax wrapped around it), then by associativity the entire history can be pre-summed into one matrix — a fixed-size associative memory that is updated once per token and never grows. Attention becomes an RNN with a matrix-valued hidden state:

\[ S_t = S_{t-1} + k_t v_t^\top, \qquad o_t = S_t^\top q_t . \]

The catch: a \(d_k \times d_v\) matrix can only hold so much. This page derives the mechanism, its three computational forms, and the capacity problem that every modern linear-attention variant — RetNet, GLA, Mamba-2, Gated DeltaNet — is an answer to.

1. Dropping the Softmax

Every attention mechanism is the same template with one slot to fill — a scoring function \(\mathrm{sim}(q, k)\) that answers "how much should this query attend to that key?":

\[ o_t = \frac{\sum_{j \le t} \mathrm{sim}(q_t, k_j)\, v_j}{\sum_{j \le t} \mathrm{sim}(q_t, k_j)} . \]

Causal softmax attention is the choice \(\mathrm{sim}(q,k) = \exp(q^\top k)\) (the \(1/\sqrt{d_k}\) scale absorbed into the vectors): the dot product measures alignment, and the exponential makes every score positive and stretches gaps so the best-matching keys dominate. Plugged into the template:

\[ o_t = \frac{\sum_{j \le t} \exp(q_t^\top k_j)\, v_j}{\sum_{j \le t} \exp(q_t^\top k_j)} . \]

As a similarity, \(\exp\) is excellent — the sharpening it provides is quantified below. The problem is its algebraic shape: \(\exp(q^\top k)\) is a joint function of the pair, so no part of it can be evaluated until both vectors are known. Nothing about the history can be preprocessed — each new query must revisit every stored key, compute every score from scratch, and re-weight every value. That is the \(O(T)\)-per-token cost of softmax decoding, and it is forced by the shape of \(\exp\), not a missed optimization:

Why exp of a dot product can never be separated

Suppose it could: \(\exp(q^\top k) = g(q)\, h(k)\) for all \(q, k\). Taking logs,

\[ q^\top k = \log g(q) + \log h(k) . \]

The left side is an interaction — its value depends on how \(q\) and \(k\) relate to each other — while the right side is a sum of two independent terms, which cannot represent any interaction. Contradiction (the only escape is infinite-dimensional, via the Taylor expansion further down). The computational stakes are the difference between \(\sum_j x^\top y_j = x^\top \bigl(\sum_j y_j\bigr)\) — where the \(y_j\) can be summed once, before \(x\) even arrives — and \(\sum_j \exp(x^\top y_j)\), which has no such shortcut because \(x\) is trapped inside every term.

Linear attention therefore fills the \(\mathrm{sim}\) slot with a similarity that is separable by construction:

Step A — Factorizable similarity

Choose a feature map \(\phi\) and score with \(\mathrm{sim}(q,k) = \phi(q)^\top \phi(k)\):

\[ o_t = \frac{\sum_{j \le t} \bigl(\phi(q_t)^\top \phi(k_j)\bigr) v_j}{\sum_{j \le t} \phi(q_t)^\top \phi(k_j)} \]

This is the kernel trick run in reverse (unpacked just below). \(\exp(q^\top k)\) is itself an inner product — just in an infinite-dimensional feature space — so softmax attention is secretly kernel attention. Step A swaps that kernel for one whose features are finite and explicit, which is what makes the factoring in Step B possible. The original paper (Katharopoulos et al., 2020) used \(\phi(x) = 1 + \mathrm{elu}(x)\) to keep scores positive; many modern variants simply use the identity. How much fidelity to the softmax this choice costs is quantified below.

Step B — Pull the query out of the sum (associativity)

\(\phi(q_t)\) does not depend on \(j\), so it factors out of both sums:

\[ o_t = \frac{\phi(q_t)^\top \overbrace{\textstyle\sum_{j \le t} \phi(k_j)\, v_j^\top}^{S_t}} {\phi(q_t)^\top \underbrace{\textstyle\sum_{j \le t} \phi(k_j)}_{z_t}} \;=\; \frac{S_t^\top \phi(q_t)}{z_t^\top \phi(q_t)} \]

Everything the history contributes is now compressed into \(S_t\) (a \(d_k \times d_v\) matrix) and \(z_t\) (a \(d_k\) vector). The sum over \(j \le t\) is still right there — so in what sense is anything "independent of \(T\)"? Look at what the sum no longer contains: the query. In softmax attention the summary a query needs, \(\sum_j \exp(q_t^\top k_j)\, v_j\), has \(q_t\) inside the sum — every query re-weights the whole history differently, so nothing can be summed once and for all, and all \(t\) keys and values must be kept around. Here the sum is a pure function of the history, the same object for every present and future query. Two consequences:

  • Fixed size. Whether ten tokens or a million have been summed, \(S_t\) is still \(d_k \times d_v\) numbers and \(z_t\) is \(d_k\). \(T\) controls how many terms went in, not how much space comes out.
  • Incremental computation. \(S_t = S_{t-1} + \phi(k_t)\, v_t^\top\) — a prefix sum. Each token folds its term in once, in \(O(d_k d_v)\), and the history never needs to be revisited. No stored \(k_j, v_j\), no \(O(T)\) work per decoded token.

So "independent of \(T\)" means the size and per-token cost are constant — not the value. \(S_t\) certainly depends on the history; encoding it is its entire job.

Modern linear-attention layers usually drop the denominator entirely: the \(z_t\) normalizer is numerically fragile (it can pass near zero) and turns out to be unnecessary if the output is normalized another way. That "another way" is exactly the per-head gated RMSNorm Qwen3-Next applies to the readout — the norm plays the softmax denominator's role, after the fact.

The kernel trick, forwards and in reverse

The classic kernel trick (the SVM-era one) starts from the feature side: you want similarity measured on a rich feature expansion — all products of coordinates, say — but the expansion is huge. For certain feature maps, the inner product has a closed form that never materializes the features. The smallest example, degree-2 monomials in \(d = 2\):

\[ \varphi(x) = \bigl(x_1^2,\ \sqrt{2}\,x_1 x_2,\ x_2^2\bigr) \quad\Longrightarrow\quad \varphi(x)^\top \varphi(y) = (x^\top y)^2 . \]

Three features per side — or just square one dot product; for higher degrees the saving grows exponential. That is the trick: want the feature-space inner product, compute the kernel \(K(x,y)\) instead. And \(\exp(q^\top k)\) is exactly such a kernel taken to its limit — the Taylor expansion below exhibits it as the inner product of all tensor-power features at once. So softmax attention has been using the kernel trick all along: every score implicitly compares two infinite-dimensional feature expansions while paying for one dot product and one exponential.

One equivalence, crossed in both directions
Kernel trick (SVM era)

The features are the expensive part (huge or infinite); data points are few. Escape: keep the features implicit, evaluate the closed-form kernel per pair. Explicit features → implicit kernel.

Reverse (attention era)

The kernel is cheap, but it couples every query–key pair — and \(T\) is the expensive part. Escape: choose explicit finite features so the sum over keys factors and is computed once. Implicit kernel → explicit features.

There is a historical rhyme here: classical kernel machines hit this same wall — \(O(T^2)\) in the number of samples — and the escape was Rahimi & Recht's random features (2007): approximate the kernel with an explicit finite feature map so everything becomes linear algebra over samples. Performer (in the table below) is precisely that move applied to the softmax kernel, and the broader linear-attention family is the same idea with the approximation requirement dropped. Which side of the equivalence you compute on depends only on which resource you have run out of.

Can a feature map actually match the softmax?

Exactly — but only with infinitely many features. Expand the exponential as a Taylor series and each term factorizes on its own:

\[ \exp(q^\top k) = \sum_{n=0}^{\infty} \frac{(q^\top k)^n}{n!}, \qquad (q^\top k)^n = \bigl\langle\, q^{\otimes n},\, k^{\otimes n} \bigr\rangle , \]

so the exact feature map is \(\phi(x) = \bigl(1,\ x,\ x^{\otimes 2}/\sqrt{2!},\ x^{\otimes 3}/\sqrt{3!},\ \dots\bigr)\) — every polynomial degree at once, with the degree-\(n\) block alone costing \(d^n\) dimensions. Any finite \(\phi\) is therefore a compromise, and the design space is which compromise:

Feature mapIdeaFidelity to the exp kernel
Identity (RetNet, GLA, DeltaNet, …) Don't approximate — accept a plain bilinear similarity None intended; scores can go negative, no sharpening
\(1 + \mathrm{elu}(x)\) (Katharopoulos et al., 2020) Keep scores positive so the denominator is safe Shape-only; not an approximation of \(\exp\)
Taylor truncation (Based, 2024) Keep the series through degree 2: \(1 + q^\top k + \tfrac{(q^\top k)^2}{2}\) Exact for small logits; \(1 + d + d^2\) features
Random features (Performer, 2021) Monte-Carlo estimate of the kernel with \(m\) sampled features Unbiased; error \(\sim 1/\sqrt{m}\), worst where attention is sharp

Performer's estimator is worth seeing once, because it makes "approximating softmax" precise. For \(\omega \sim \mathcal{N}(0, I)\), the identity

\[ \exp(q^\top k) \;=\; \mathbb{E}_{\omega}\!\left[ e^{\omega^\top q - \lVert q \rVert^2/2}\; \cdot\; e^{\omega^\top k - \lVert k \rVert^2/2} \right] \]

holds exactly, and each factor inside the expectation depends on \(q\) or \(k\) alone — so sampling \(m\) values of \(\omega\) gives an \(m\)-dimensional random \(\phi\) whose inner product is an unbiased estimate of the softmax kernel. The catch is the variance: it shrinks as \(1/m\) but carries a constant that grows exponentially with the logit magnitude. The approximation is accurate exactly where attention is diffuse and unreliable exactly where attention is sharp — and sharp, near-one-hot retrieval is where softmax attention earns its keep.

That points at the deeper issue: the accuracy question is less about approximating the number \(\exp(q^\top k)\) than about two structural properties no finite \(\phi\) recovers:

  • Rank. The linear attention matrix \(\phi(Q)\phi(K)^\top\) has rank at most \(m\) (the feature dimension); a softmax attention matrix is generically full rank. A \(T \times T\) pattern with \(T \gg m\) sharply-selected entries simply doesn't fit in rank \(m\).
  • Competition. Softmax makes keys compete: exponentiate, then renormalize, and a modest score gap becomes a near-one-hot winner. A factorized similarity is additive — every key contributes independently, and nothing suppresses the losers. The plot below makes this concrete.
softmax: \(\sigma(\Delta)\), any base score linear, base score s = 1 linear, base score s = 4

Softmax can do winner-take-all; a factorized similarity cannot. Two keys compete for a query: the weaker scores \(s\), the stronger \(s + \Delta\). Softmax gives the winner a share \(\sigma(\Delta)\) of the readout — it saturates toward 1 exponentially fast and depends only on the margin \(\Delta\), not the base score. Normalized linear attention gives \((s{+}\Delta)/(2s{+}\Delta)\): it approaches 1 only harmonically, and the larger the base score, the flatter it gets. The losing key is never truly silenced — which, multiplied over thousands of keys, is the interference problem of §4.

The field's eventual answer was to stop chasing \(\exp\) altogether. Modern linear attentions use the identity map and spend their effort on the mechanism instead — decay gates, the delta rule, output normalization — accepting a different similarity rather than a worse copy of the old one. The accuracy question then stops being a kernel-approximation error and becomes a capability gap, measured on recall-intensive tasks (exact retrieval over long context, in-context lookups) — which is precisely the gap the hybrid stacks of §4 paper over with a few real softmax layers.

2. Attention as an RNN

Because \(S_t\) is a prefix sum, it updates incrementally — one rank-1 write per token:

Result — linear attention, recurrent form
\[ S_t = S_{t-1} + k_t v_t^\top, \qquad o_t = S_t^\top q_t \]

(feature maps absorbed into \(q, k\); denominator dropped)

Read it as an associative memory:

  • Write: the outer product \(k_t v_t^\top\) stores the association "key \(k_t\) ↦ value \(v_t\)" superimposed onto everything already in \(S\).
  • Read: \(S_t^\top q_t = \sum_{j \le t} (k_j^\top q_t)\, v_j\) retrieves a mixture of all stored values, weighted by how much each key aligns with the query — un-normalized attention weights.

Per decoded token this costs \(O(d_k d_v)\) compute and \(O(d_k d_v)\) memory — constant in \(T\). The comparison with the KV cache is stark:

softmax attention: KV cache = 2·T·d floats linear attention: state = d × d floats

The state never grows. Per-head decode-time memory (in K floats) versus context length, for head dimension \(d = 128\). The KV cache passes the fixed \(d \times d\) state at just \(T = 64\) tokens and keeps climbing — at a 32k context it is 512× larger, and every decoded token must read all of it. GQA shrinks the softmax line by a constant factor; it cannot change the slope.

3. One Mechanism, Three Computational Forms

The same equations evaluate three ways, and a production layer uses all three — this duality is the reason linear attention is practical at all:

FormComputationCostUsed for
Parallel \(O = \bigl(QK^\top \odot M\bigr)V\) with causal mask \(M\) \(O(T^2 d)\) Short sequences; identical to un-normalized attention
Recurrent \(S_t = S_{t-1} + k_t v_t^\top;\ o_t = S_t^\top q_t\) \(O(T\, d_k d_v)\), sequential Decoding — one rank-1 update per token
Chunked Split \(T\) into chunks of \(C\): exact parallel attention within a chunk + recurrent state carried between chunks \(O(T C d + T\, d_k d_v)\), matmul-heavy Training and prefill — tensor-core friendly

The chunked form is the workhorse: within a chunk, tokens attend to each other with dense matmuls (parallel form); the inter-chunk history arrives through the state (recurrent form). Sequence length enters only linearly, and all the heavy work is matrix multiplication. This is what chunk_gated_delta_rule computes in Qwen3-Next's prefill path.

4. What You Lose — and the Fix Ladder

Softmax attention is a lossless lookup: every key–value pair remains individually addressable forever. Linear attention compresses the whole history into \(d_k \times d_v\) numbers, and the additive write is where it hurts. Retrieving a stored item returns the item plus interference from everything else:

\[ S_T^\top k_i \;=\; \underbrace{(k_i^\top k_i)\, v_i}_{\text{what you wanted}} \;+\; \underbrace{\textstyle\sum_{j \ne i} (k_j^\top k_i)\, v_j}_{\text{crosstalk from every other item}} \]

Random directions in \(d\) dimensions overlap by \(\sim 1/\sqrt{d}\) on average, so crosstalk grows with the number of stored items — the memory gets noisier with every write, and nothing is ever removed. The escalating fixes:

  1. Decay (RetNet): \(S_t = \gamma S_{t-1} + k_t v_t^\top\) with a fixed \(\gamma \in (0,1)\) — old associations fade geometrically, bounding total interference at the price of a hard-coded recency bias.
  2. Gated decay (GLA, Mamba-2): \(S_t = \alpha_t\, S_{t-1} + k_t v_t^\top\) with \(\alpha_t\) computed from the input — the model decides when to forget.
  3. The delta rule (DeltaNet, Gated DeltaNet): stop adding blindly — read what the memory already predicts for this key and write only the correction, overwriting stale associations instead of superimposing onto them. Derived in full on the Gated DeltaNet page.
  4. Hybrid stacks (Qwen3-Next, MiniMax-01): accept that a fixed state can't do exact long-range recall, and interleave a few full-attention layers into a mostly-linear stack — Qwen3-Next runs 3 Gated DeltaNet layers for every 1 softmax-attention layer.

5. Summary

The trick

Factorizable similarity → associativity → history pre-summed into \(S_t = \sum \phi(k_j) v_j^\top\)

The win

\(O(1)\) state and \(O(1)\) work per decoded token, vs \(O(T)\) for softmax attention

The cost

Fixed capacity: additive writes interfere and recall blurs as context grows

The fixes

Decay → gated decay → delta rule → hybrid stacks with a few softmax layers
