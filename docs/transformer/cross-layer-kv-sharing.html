CLA & YOCO — Cross-Layer KV Sharing

Every layer can ask a new question without writing a new copy of the history. Follow cache ownership through projections, scoring, softmax, and output, then see why YOCO changes which prompt positions need upper-layer computation.

Reading path: ordinary attention → KV caching → this guide. MLA compresses each stored position; CLA/YOCO reduce the number of distinct layer memories. These are architectural choices requiring appropriate training, not transparent switches for any existing checkpoint.

1. Separate the reader from the memory producer

In ordinary attention, the same block input supplies Q, K, and V. With cross-layer sharing, a consumer makes Q from its current hidden states but reads K/V produced earlier in the network. Scores, softmax probabilities, output projections, residual states, and FFNs remain specific to the consumer.

Ordinary:
  block A: Q_A, K_A, V_A from input_A
  block B: Q_B, K_B, V_B from input_B

Classical CLA:
  block A: produce K_A/V_A; Q_A reads that memory
  block B: Q_B from input_B reads the SAME K_A/V_A

Pure YOCO:
  lower self-decoder -> one global K/V bank
  upper block 0: fresh Q -> shared bank
  upper block 1: fresh Q -> shared bank
  ...

Sharing activations is not tying projection weights. Applying the same matrix to two different layer inputs generally produces different K/V. Sharing the actual produced tensors is what removes the duplicate cache.

2. CLA: a different query, the same historical representation

For a consumer at layer \(l\) using a producer \(s(l)\), classical CLA computes:

\[ Q_l=\operatorname{Norm}(X_l)W^Q_l,\quad A_l=\operatorname{softmax}\left( Q_lK_{s(l)}^\top/\sqrt{d_k}+\mathrm{mask}\right),\quad Y_l=\operatorname{ConcatHeads}(A_lV_{s(l)})W^O_l. \]

The layer then applies its normal residual and FFN path. A two-layer sharing group stores one K/V history, but both attention reads still run. The consumer may reread the same cache from device memory; a twofold cache-capacity reduction is not automatically a twofold latency reduction. Nor can a later query recover information that the shared memory failed to encode.

StepShapeOwner
Q projection and head split[B,H,T,d]Current consumer
K and V[B,H,S,d]Earlier producer in this MHA example
QK scores, mask, softmax over S[B,H,T,S]Recomputed by each consumer
Weighted V, head concatenation, WO[B,T,D]Current consumer

T and S need not match: one decoding query can read an entire prefix. This guide uses equal Q/KV head counts; CLA can also compose with GQA/MQA.

3. One block implementation for producers and consumers

Copy the following Python blocks in order. They are small, dependency-light PyTorch reference examples, not paper checkpoints or serving kernels. They use ordinary MHA, LayerNorm and a GELU FFN, omitting RoPE, dropout, GQA, padding and quantization. The examples below run in CPU float64; mixed-precision implementations need their own accumulation and normalization policy.

import math
import torch
from torch import nn


def split_heads(x, heads):
    batch, length, dim = x.shape
    return x.reshape(batch, length, heads, dim // heads).transpose(1, 2)


def visible_positions(query_pos, key_pos, window=None):
    allowed = key_pos[None, :] <= query_pos[:, None]
    if window is not None:
        allowed = allowed & (
            key_pos[None, :] > query_pos[:, None] - window
        )
    return allowed


class Block(nn.Module):
    def __init__(self, dim, heads, owns_kv):
        super().__init__()
        assert dim % heads == 0
        self.heads, self.head_dim = heads, dim // heads
        self.norm1, self.norm2 = nn.LayerNorm(dim), nn.LayerNorm(dim)
        self.q = nn.Linear(dim, dim, bias=False)
        self.k = nn.Linear(dim, dim, bias=False) if owns_kv else None
        self.v = nn.Linear(dim, dim, bias=False) if owns_kv else None
        self.out = nn.Linear(dim, dim, bias=False)
        self.ffn = nn.Sequential(
            nn.Linear(dim, 4 * dim), nn.GELU(), nn.Linear(4 * dim, dim)
        )

    def forward(self, x, query_pos, kv=None, key_pos=None, window=None):
        z = self.norm1(x)
        q = split_heads(self.q(z), self.heads)
        if self.k is not None:
            if kv is not None:
                raise ValueError("Producer must build its own K/V")
            kv = (split_heads(self.k(z), self.heads),
                  split_heads(self.v(z), self.heads))
            key_pos = query_pos
        elif kv is None or key_pos is None:
            raise ValueError("Consumer needs shared K/V and their positions")

        k, v = kv
        scores = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        allowed = visible_positions(query_pos, key_pos, window)
        scores = scores.masked_fill(~allowed[None, None], -torch.inf)
        probabilities = scores.softmax(dim=-1)
        context = probabilities @ v
        merged = context.transpose(1, 2).reshape(x.shape)
        x = x + self.out(merged)
        return x + self.ffn(self.norm2(x)), kv

PyTorch stores linear weights as [out_features,in_features]. No projection is shared accidentally: the consumer has its own Q and output weights, but no K/V producer weights. Every query must have at least one valid key; packed or padded requests need additional masking beyond this example.

torch.manual_seed(7)
producer = Block(dim=12, heads=3, owns_kv=True).double()
consumer = Block(dim=12, heads=3, owns_kv=False).double()
x = torch.randn(2, 6, 12, dtype=torch.float64)
positions = torch.arange(x.shape[1])

h, bank = producer(x, positions)
y, reused_bank = consumer(h, positions, kv=bank, key_pos=positions)
assert reused_bank[0] is bank[0]  # Same activation tensor, not a clone.

This evaluates all sequence positions, with causal masking. It does not yet append a persistent inference cache. During training, keep bank connected to autograd: consumer gradients must reach the producer as well.

4. YOCO: a lower writer stack and an upper reader stack

Pure YOCO uses a causal self-decoder with bounded-size local/recurrent state, followed by a cross-decoder that reads a shared global bank. The paper supports sliding-window attention or gated retention in the lower stage. Here we use sliding windows.

input embeddings
    |
    v
lower local block 0 -> lower local block 1 -> H_mid
                                              |
                             memory normalization + K/V projections
                                              |
                                              v
                                      ONE global bank
                                              |
H_mid -> upper reader 0 -> upper reader 1 -> output
             |                  |
             +-- read bank -----+

Each upper reader keeps its own Q, scores, softmax, W_out, residuals and FFN.

The global bank is newly projected from the output of the lower stack; it is not simply the internal attention cache of its last block. Both stages remain causal. “Cross-attention” means the query and memory originate in different network stages, not that there is a separate bidirectional input encoder.

Why the upper stage can skip most prompt positions

To predict the first continuation token, only the last prompt position needs final logits. In a normal transformer, earlier prompt positions must still populate every upper layer's K/V. Pure YOCO's upper layers have no such histories to produce: all of their memory already comes from the lower stage.

Thus, process the entire prompt through the lower stage, build the global bank, and send just the final prompt position through the upper stage. Each upper block reads the full causal bank. This is equivalent to taking the last output of the full forward pass when the upper FFNs/norms are per-position and stochastic effects are disabled. Training or scoring every prompt position still needs all outputs.

class ToyYOCO(nn.Module):
    def __init__(self, dim=12, heads=3, window=3):
        super().__init__()
        self.heads, self.window = heads, window
        self.lower = nn.ModuleList([
            Block(dim, heads, owns_kv=True) for _ in range(2)
        ])
        self.memory_norm = nn.LayerNorm(dim)
        self.memory_k = nn.Linear(dim, dim, bias=False)
        self.memory_v = nn.Linear(dim, dim, bias=False)
        self.upper = nn.ModuleList([
            Block(dim, heads, owns_kv=False) for _ in range(2)
        ])
        self.final_norm = nn.LayerNorm(dim)
        self.lm_head = nn.Linear(dim, 32, bias=False)

    def forward(self, x, last_only=False):
        positions = torch.arange(x.shape[1], device=x.device)
        h = x
        for block in self.lower:
            h, _ = block(h, positions, window=self.window)

        z = self.memory_norm(h)
        bank = (split_heads(self.memory_k(z), self.heads),
                split_heads(self.memory_v(z), self.heads))
        queries = h[:, -1:] if last_only else h
        query_pos = positions[-1:] if last_only else positions
        for block in self.upper:
            queries, _ = block(
                queries, query_pos, kv=bank, key_pos=positions
            )
        return self.lm_head(self.final_norm(queries))


model = ToyYOCO().double().eval()
with torch.no_grad():
    full = model(x)
    last = model(x, last_only=True)
    torch.testing.assert_close(last, full[:, -1:], rtol=1e-9, atol=1e-10)

    # Future tokens must not affect earlier outputs.
    changed = x.clone()
    changed[:, 3:] += 10 * torch.randn_like(changed[:, 3:])
    torch.testing.assert_close(
        model(changed)[:, :3], full[:, :3], rtol=1e-9, atol=1e-10
    )
print("YOCO last-position and causal outputs agree.")
Semantics, not peak memory: the lower blocks above materialize dense score tensors and full-sequence K/V, then mask them. A local mask alone does not implement a bounded-memory kernel. Production serving needs window-aware attention, bounded local caches, and one growing global bank.

5. What memory is actually saved?

For equal KV widths and precision, let \(c=2BH_{\rm KV}d_{\rm head}b\) be bytes per stored token position per bank. With \(L\) total layers, sharing factor \(g\), \(L_s\) lower YOCO layers and window \(W\):

\[ M_{\rm full}=cLT,\qquad M_{\rm CLA}=c\lceil L/g\rceil T,\qquad M_{\rm YOCO}=c\left[T+L_s\min(T,W)\right]. \]

“Once” means one global bank, not zero lower-stage state and not a bank that never changes. Every new token adds one global entry and updates the lower local caches. Recurrent self-decoders have a different fixed-state term.

6. Make the ownership contract explicit

BoundaryImplementation requirement
DecodeRun the new token through lower blocks using their local state; create and append one new global K/V entry; let every upper block read it. Do not append once per reader.
StorageConsumers reference the producer's bank. Use preallocated/paged global storage and ring buffers for windows rather than repeatedly copying a growing prefix.
PositionsUse absolute query/key positions and per-request validity masks. Apply any rotary positional encoding consistently; do not rotate a shared cached key again at each reader.
EvictionKeep entries until every consumer is done. In chunked prefill, an early query can need positions older than the final query's window; trim only after the required reads.
TrainingRetain the producer graph so gradients from all readers accumulate into it. Inference caches and deliberate truncated backpropagation are different policies, not reasons to detach ordinary training activations.
Pipeline parallelismColocate sharing layers or transfer the shared activations across stages. Cache capacity saved does not eliminate communication or cache reads.
ChecksCompare full versus chunked/token decoding, future-token perturbations, last-position YOCO prefill, producer gradients, and physical cache ownership. Define tolerances for the chosen dtype/backend.

7. Classical K/V sharing is not MLA latent sharing

Classical CLA / pure YOCO:
    producer -> K_shared, V_shared
    reader A: Q_A reads the same K_shared/V_shared
    reader B: Q_B reads the same K_shared/V_shared

MLA latent sharing:
    producer -> C_shared
    reader A: own Q_A and own K/V expansion of C_shared
    reader B: own Q_B and own K/V expansion of C_shared

In the latter case the expanded K/V can differ across readers even though the persistent latent is identical. This is the boundary between the examples above and Mistral's released implementation. Both readers remain limited by what the source encoded into the shared latent.

Mistral's original architecture interleaved local and global layers and shared the first-half anchor with selected upper global layers; it was not pure YOCO. Its later surgery removed sliding-window restrictions and CLA, but retained limited YOCO-style sharing. Therefore the simple last-position-only upper-stage shortcut is not a drop-in optimization for that hybrid. Its independent upper-layer histories impose additional dependencies.

For a related distinction, ragged attention changes which positions a layer may read (for example, three local layers per global layer); it does not by itself share a bank. MLA's code walkthrough owns latent compression and absorbed execution; hybrid attention covers mixed sequence-mixer stacks.
