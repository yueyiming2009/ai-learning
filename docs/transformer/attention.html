Transformer & Pretraining

Self-Attention — Forward & Backward Pass

The mixing operation at the heart of the transformer: queries, keys, and values; why the scores are scaled by \(1/\sqrt{d_k}\); the causal mask; the multi-head split; and the full gradient back through softmax.

1. The Idea — Content-Based Retrieval

Every other block in a transformer processes each token independently — the MLP, the norm, the activation all act position by position. Attention is the one place where tokens look at each other. It is the layer that lets "it" find its antecedent and a verb find its subject.

The mechanism is a soft, differentiable dictionary lookup. Each token emits three vectors:

  • a query \(\mathbf{q}\) — "what am I looking for?"
  • a key \(\mathbf{k}\) — "what do I offer?"
  • a value \(\mathbf{v}\) — "what do I pass along if selected?"

Token \(i\) compares its query against every key by a dot product, turns those similarities into a probability distribution with softmax, and reads out a weighted average of the values. A high query·key alignment means "attend here"; the value at that position dominates the output.

The whole operation is permutation-equivariant — it has no built-in notion of order. Position information must be injected separately, which is exactly the job of RoPE (rotating \(\mathbf{q}\) and \(\mathbf{k}\)) or additive positional encodings.

3. Scaled Dot-Product Attention — Forward

Step 1 — Project to Q, K, V

One shared input \(X\) is read three ways:

\[ Q = XW_Q, \qquad K = XW_K, \qquad V = XW_V \]

These are the only learned parameters inside a single head. Everything that follows is parameter-free arithmetic.

Step 2 — Score every query against every key

The unnormalized similarity between query \(i\) and key \(j\) is their dot product, scaled:

\[ S_{ij} = \frac{\mathbf{q}_i \cdot \mathbf{k}_j}{\sqrt{d_k}} \qquad\Longleftrightarrow\qquad S = \frac{QK^\top}{\sqrt{d_k}} \]

\(S\) is a \(T\times T\) matrix: row \(i\) holds the scores token \(i\) assigns to all positions. The \(1/\sqrt{d_k}\) factor is derived in §4.

Step 3 — Causal mask (decoder)

In an autoregressive LM, token \(i\) may not see the future. Before softmax, set the upper triangle to \(-\infty\):

\[ S_{ij} \leftarrow -\infty \quad \text{for } j > i \]

After softmax those entries become exactly \(0\), so each token attends only to itself and earlier positions. (Encoders and bidirectional models simply skip this step.)

Step 4 — Softmax into a distribution

Each row is normalized into attention weights that sum to 1:

\[ P_{ij} = \frac{\exp(S_{ij})}{\sum_{l=1}^{T}\exp(S_{il})} \]

In practice the row max is subtracted first for numerical stability (the same trick derived in cross entropy) — it shifts every logit and leaves \(P\) unchanged.

Step 5 — Weighted sum of values

The output for token \(i\) is the convex combination of value vectors picked out by row \(i\):

\[ \mathbf{o}_i = \sum_{j=1}^{T} P_{ij}\,\mathbf{v}_j \qquad\Longleftrightarrow\qquad O = PV \]
Scaled Dot-Product Attention
\[ \mathrm{Attn}(Q,K,V) = \underbrace{\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)}_{P}\,V \]

\(M\) is the additive mask: \(0\) where attention is allowed, \(-\infty\) where it is forbidden.

4. Why Divide by \(\sqrt{d_k}\)?

This is the one "magic constant" in attention, and it follows from a one-line variance argument. Model the components of \(\mathbf{q}\) and \(\mathbf{k}\) as independent, zero-mean, unit-variance random variables. The dot product is a sum of \(d_k\) such products:

\[ \mathbf{q}\cdot\mathbf{k} = \sum_{m=1}^{d_k} q_m k_m, \qquad \mathrm{Var}(\mathbf{q}\cdot\mathbf{k}) = \sum_{m=1}^{d_k}\mathrm{Var}(q_m k_m) = d_k \]

So the raw scores have standard deviation \(\sqrt{d_k}\) — they grow with head size. Feed logits of magnitude \(\sim\!\sqrt{d_k}\) into softmax and, for large \(d_k\), one entry dominates: the distribution collapses toward one-hot. That is exactly the regime where the softmax Jacobian \(P_{ij}(1-P_{ij})\) vanishes and gradients die. Dividing by \(\sqrt{d_k}\) renormalizes the variance back to \(1\), independent of head dimension.

5. Multi-Head Attention

A single head can only express one mixing pattern per layer. Multi-head attention runs \(h\) independent heads in parallel — each with its own \(W_Q^{(\ell)}, W_K^{(\ell)}, W_V^{(\ell)}\) — so one head can track syntax while another tracks coreference. Crucially this costs nothing extra in width: each head works in the smaller dimension \(d_k = d/h\), so total work matches a single full-width attention.

Per-head, then concatenate

Run scaled dot-product attention \(h\) times and stack the \(d_v\)-wide outputs side by side:

\[ \mathrm{head}_\ell = \mathrm{Attn}(XW_Q^{(\ell)},\, XW_K^{(\ell)},\, XW_V^{(\ell)}) \in \mathbb{R}^{T\times d_v} \] \[ \mathrm{MHA}(X) = \big[\,\mathrm{head}_1 \,\Vert\, \cdots \,\Vert\, \mathrm{head}_h\,\big]\,W_O \]

The concatenation is \(T\times h d_v = T\times d\); the output projection \(W_O\) mixes information across heads and maps back to the residual stream.

The KV side is where inference memory goes. Grouped-query and multi-query attention share one set of \(K,V\) across several query heads — fewer key/value projections, a smaller KV cache, identical query-side math.

6. Backward Pass

Given the upstream gradient \(dO = \partial L/\partial O\), we walk back through the five forward steps. The only non-trivial node is the softmax; everything else is a matrix multiply, and its vector–Jacobian product is a transpose.

Step 5′ — Through \(O = PV\)

A product of two matrices has two gradients, each a multiply by the other factor transposed:

\[ dV = P^\top\,dO, \qquad dP = dO\,V^\top \]
Step 4′ — Through the row-wise softmax

Softmax acts independently on each row, so work one row \(i\) at a time. The Jacobian of \(P_i = \mathrm{softmax}(S_i)\) gives

\[ dS_{ij} = P_{ij}\Big(dP_{ij} - \sum_{l} P_{il}\,dP_{il}\Big) \]

The subtracted term is the same for the whole row. Substituting \(dP_{il} = \mathbf{do}_i\cdot\mathbf{v}_l\) collapses it into a remarkably clean form:

\[ \sum_l P_{il}\,dP_{il} = \mathbf{do}_i\cdot\!\sum_l P_{il}\mathbf{v}_l = \mathbf{do}_i\cdot\mathbf{o}_i \] \[ \boxed{\,dS_{ij} = P_{ij}\big(\mathbf{do}_i\cdot\mathbf{v}_j - \mathbf{do}_i\cdot\mathbf{o}_i\big)\,} \]

That row constant \(\mathbf{do}_i\cdot\mathbf{o}_i\) is exactly the quantity FlashAttention recomputes on the fly to avoid storing the full \(T\times T\) matrix \(P\).

Step 2′ — Through the scaled scores

Undo the scale, then split the matrix product \(QK^\top\) into its two factors:

\[ dQ = \frac{1}{\sqrt{d_k}}\,dS\,K, \qquad dK = \frac{1}{\sqrt{d_k}}\,dS^\top Q \]

Note the transpose: query \(i\)'s gradient pulls from every key it scored, and key \(j\)'s gradient gathers from every query that scored it.

Step 1′ — Through the projections

Each of \(Q,K,V\) came from \(X\) times a weight matrix, so the pattern repeats once more — weight gradient is input\(^\top\) times output gradient, and the input accumulates a contribution from all three paths:

\[ dW_Q = X^\top dQ,\quad dW_K = X^\top dK,\quad dW_V = X^\top dV \] \[ dX = dQ\,W_Q^\top + dK\,W_K^\top + dV\,W_V^\top \]

For multi-head, prepend the output projection: \(dW_O = \mathrm{Concat}^\top\,d(\mathrm{MHA})\) and \(d(\mathrm{Concat}) = d(\mathrm{MHA})\,W_O^\top\), then split \(d(\mathrm{Concat})\) back into per-head slices and run the above per head.

7. Compute & Memory Cost

Two matrix multiplies dominate: \(QK^\top\) and \(PV\). Each is \(T\times T\times d_k\), summed over \(h\) heads (\(hd_k=d\)):

\[ \text{FLOPs} \approx \underbrace{2T^2 d}_{QK^\top} + \underbrace{2T^2 d}_{PV} = 4T^2 d \quad\text{(per layer, forward)} \]

The \(T^2\) is the whole story of attention's reputation. Compute and — in a naive implementation — the memory to hold \(P\) both grow quadratically in sequence length. That single fact drives three of the most important systems ideas on this site:

  • FlashAttention — never materialize the \(T\times T\) matrix; tile and recompute, turning \(O(T^2)\) memory into \(O(T)\).
  • Ring / sequence parallelism — shard the \(T\) axis across GPUs when one device can't hold the sequence.
  • KV caching — at inference, reuse past \(K,V\) so each new token is \(O(T)\), not \(O(T^2)\).

8. Summary

Forward

\(O = \mathrm{softmax}\!\big(\tfrac{QK^\top}{\sqrt{d_k}}+M\big)V\)

Why \(1/\sqrt{d_k}\)

Keeps logit variance at 1 so softmax doesn't saturate and kill gradients

Multi-head

\(h\) heads in dim \(d/h\), concat, then \(W_O\) — same cost, many patterns

Softmax backward

\(dS_{ij}=P_{ij}(\mathbf{do}_i\!\cdot\!\mathbf{v}_j-\mathbf{do}_i\!\cdot\!\mathbf{o}_i)\)

Score gradients

\(dQ=\tfrac{1}{\sqrt{d_k}}dS\,K,\ \ dK=\tfrac{1}{\sqrt{d_k}}dS^\top Q\)

Cost

\(\sim 4T^2d\) FLOPs/layer; \(O(T^2)\) — the quadratic wall
