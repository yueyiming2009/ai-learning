Transformer & Pretraining

The Transformer Block

How the isolated pieces — norm, attention, MLP, residuals — snap together into one repeatable block, and how a stack of them between an embedding and an unembedding becomes a decoder-only language model.

The attention page built the mixing operation; the norm, SwiGLU, and RoPE pages built the other parts. This page does the assembly: it shows the single structural motif that every modern LLM — LLaMA, Qwen, DeepSeek, Mistral — repeats dozens of times, and why it is shaped the way it is.

1. The Residual Stream

The right mental model for a transformer is not a pipeline that transforms data stage by stage. It is a residual stream: a running sum, one \(d\)-dimensional vector per token, that every layer reads from and writes back into.

\[ \mathbf{x}_{\ell+1} = \mathbf{x}_\ell + \mathrm{sublayer}(\mathbf{x}_\ell) \]

Each sublayer doesn't replace the stream — it computes a delta and adds it. This single design choice does three things at once:

  • Gradient highway. The \(+\mathbf{x}_\ell\) term means the backward pass has a path of derivative exactly \(1\) straight from the loss to every layer: \(\partial \mathbf{x}_{\ell+1}/\partial \mathbf{x}_\ell = I + \partial(\mathrm{sublayer})/\partial \mathbf{x}_\ell\). Gradients can't vanish through the identity branch, which is what makes 100-layer depth trainable.
  • Incremental computation. Each layer only has to learn a correction to the stream, not reconstruct it from scratch.
  • A shared bus. Layer 30 can read something layer 2 wrote, because it is all the same additive accumulator.
Residual connections are the reason normalization is even necessary. Adding a delta every layer makes the stream's magnitude grow with depth; a norm at the entrance of each sublayer rescales it back to a controlled range before the matmuls. The two features are co-dependent.

2. Pre-Norm vs. Post-Norm

Where you place the norm decides whether the residual stream stays a clean highway. Two choices:

Post-Norm (original 2017)Pre-Norm (every modern LLM)
Formula\(\mathbf{x}_{\ell+1}=\mathrm{Norm}(\mathbf{x}_\ell+\mathrm{sub}(\mathbf{x}_\ell))\)\(\mathbf{x}_{\ell+1}=\mathbf{x}_\ell+\mathrm{sub}(\mathrm{Norm}(\mathbf{x}_\ell))\)
Residual pathpasses through the normstays clean (identity)
Deep trainingneeds careful LR warmup; unstable past ~12 layers without tricksstable to 100+ layers out of the box
Used byoriginal Transformer, BERTGPT-2 onward, LLaMA, Qwen, …

The reason pre-norm won is exactly the gradient-highway argument from §1: in pre-norm the norm sits inside the sublayer branch, so the \(+\mathbf{x}_\ell\) skip is a pure identity with derivative \(1\). In post-norm the skip runs through the norm's Jacobian at every layer, and those Jacobians multiply — the highway gets resistors in series. This page assumes pre-norm throughout.

3. The Block — Two Sublayers

A transformer block is just the residual motif applied twice: once with attention as the sublayer, once with the MLP. Modern blocks also use RMSNorm (no mean subtraction, cheaper) and a SwiGLU MLP.

\(\mathbf{x}_{\ell+1}\) — residual stream out
Sublayer 1 — Attention mixes across tokens
\[ \mathbf{a}_\ell = \mathbf{x}_\ell + \mathrm{MHA}\big(\mathrm{RMSNorm}(\mathbf{x}_\ell)\big) \]

This is the only sublayer where information moves between positions. RoPE is applied to \(Q\) and \(K\) inside the MHA call.

Sublayer 2 — MLP processes each token
\[ \mathbf{x}_{\ell+1} = \mathbf{a}_\ell + \mathrm{SwiGLU}\big(\mathrm{RMSNorm}(\mathbf{a}_\ell)\big) \]

The MLP acts on each position independently, expanding to a hidden width \(\approx \tfrac{8}{3}d\) and back. This is where most of the parameters and most of the per-token FLOPs live — it is the model's "knowledge" store.

One Pre-Norm Transformer Block
\[ \mathbf{a} = \mathbf{x} + \mathrm{MHA}(\mathrm{RMSNorm}(\mathbf{x})), \qquad \mathbf{x}' = \mathbf{a} + \mathrm{SwiGLU}(\mathrm{RMSNorm}(\mathbf{a})) \]
The division of labor is clean and worth memorizing: attention moves information between tokens; the MLP transforms it within a token. Stack the two and you can both gather context and compute on it — repeatedly.

4. The Stack — Depth

⋮

↓
final RMSNorm
↓

A single final RMSNorm sits after the last block (the pre-norm stream is never normalized at the very top otherwise). \(L\) ranges from ~12 (small) to 80+ (frontier). Depth and width \(d\) are the two main scaling dials — see scaling laws.

5. Embedding and Unembedding

The stack operates on continuous vectors, but the input and output are discrete token IDs. Two lookup/projection matrices bridge that gap.

Embedding — IDs to vectors

The embedding matrix \(E \in \mathbb{R}^{V\times d}\) (vocabulary \(V\), e.g. 128k rows) is a lookup table. Token ID \(t\) becomes row \(\mathbf{e}_t\), the initial residual-stream value \(\mathbf{x}_0\). No positional vector is added — modern models inject position through RoPE inside attention instead.

Unembedding — vectors to logits

After the final norm, project the \(d\)-dim stream back to vocabulary size to get a score per token:

\[ \mathbf{z}_i = \mathbf{x}^{\text{final}}_i\, U, \qquad U \in \mathbb{R}^{d\times V} \]

These logits \(\mathbf{z}_i\) feed the softmax + cross-entropy loss during training, or the sampler at inference.

Weight tying: many models set \(U = E^\top\) — the same matrix embeds and unembeds. It saves \(V\!\times\!d\) parameters (often >100M) and reflects a real symmetry: the geometry that maps a token into the stream is a sensible one for reading it back out. GPT-2 and many LLaMA-class models tie; some large models keep them separate.

6. Parameter & FLOP Budget

Per block, the parameters split cleanly between the two sublayers (ignoring norms, which are negligible):

ComponentParametersNote
Attention \(W_Q,W_K,W_V,W_O\)\(4d^2\)fewer with GQA on the KV side
SwiGLU MLP (3 matrices, hidden \(\tfrac{8}{3}d\))\(3\cdot d\cdot\tfrac{8}{3}d = 8d^2\)the bulk of the block
Per block total\(\approx 12d^2\)×\(L\) blocks
Embedding (+ untied unembed)\(Vd\) (or \(2Vd\))dominates at small \(L\), tiny at scale

So total non-embedding parameters \(N \approx 12 L d^2\). This is exactly the \(N\) that the \(6N\) FLOPs-per-token rule and the scaling laws are written in terms of — the transformer block is where that \(N\) physically comes from.

The backward pass is just the residual motif run in reverse: gradient flows back through the unembedding, down the stack, and at every \(\oplus\) it splits — one copy continues along the clean skip, one enters the sublayer's VJP. Each sublayer's internal gradients are exactly the attention, SwiGLU, and RMSNorm derivations on their own pages. Nothing new to derive — that is the payoff of building the pieces first.
