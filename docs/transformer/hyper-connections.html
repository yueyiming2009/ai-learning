Rewiring the Residual Stream

Hyper-connections, DeepSeek's Sinkhorn-constrained mHC, and Kimi's Attention Residuals: two frontier labs replaced 2017's uniform residual sum in the same half-year — with the same underlying constraint in different clothes.

The residual stream is the transformer's least-questioned component: every sublayer computes something and adds it to a running vector, \(x \mathrel{+}= f(x)\), 61 or 93 times in a row. It is a gradient highway, it needs no parameters, and it has been untouched through every attention and FFN revolution — until 2026, when DeepSeek-V4 (mHC) and Kimi K3 (Block AttnRes) both shipped replacements. This page covers what's wrong with the uniform sum, the two fixes, and the one mathematical idea they share.

1. What the Uniform Sum Gets Wrong (and Right)

After \(L\) sublayers the stream is \(x_L = x_0 + \sum_{\ell<L} f_\ell\) — every layer reads the same undifferentiated sum and writes with the same fixed weight 1. Two structural costs:

  • Dilution. Layer 20's output reaches layer 80 as one summand among eighty. If it matters a lot to layer 80 specifically, tough — its relative weight is fixed at \(1/L\)-ish, and the only remedy is for other layers to waste capacity re-amplifying it.
  • No routing across depth. The stream is one lane: a layer cannot address "what layer 20 computed" separately from "what layer 60 computed." Features must coexist superposed in one vector.
  • And the thing it gets right, which any replacement must preserve: the identity path. Gradients reach layer 1 unattenuated, and signal magnitude is stable — adding \(L\) roughly independent contributions grows the norm only like \(\sqrt{L}\), which the norms absorb.

Why "just learn the mixing weights" fails at 93 layers. Relative signal magnitude vs. depth. An unconstrained learned mixing whose effective gain sits just 5% above 1 amplifies 90× by layer 93; 5% below, it kills the stream to 1% — and nothing in SGD pins the gain to exactly 1. The uniform sum (dashed) grows a benign \(\sqrt{L}\). Both 2026 redesigns buy their flexibility under a convex-combination constraint (violet): mixing weights that are non-negative and sum to 1 can re-route mass but never create it, so the magnitude stays bounded at any depth.

2. Hyper-Connections — Widen and Learn the Wiring

Hyper-connections (ByteDance, 2024) generalize the stream: instead of one lane, keep \(n\) parallel lanes (expansion rate \(n = 2\)–4), and let each layer apply learned maps for how it reads from the lanes, how it writes back, and how the lanes mix with each other across the layer boundary. The uniform sum is the special case (one lane, identity mixing, weight-1 write). The original paper showed consistent pretraining gains — and the obvious hazard: the lane-mixing matrix is applied at every layer, so any systematic deviation of its gain from 1 compounds geometrically (the amber/teal curves above). At 60–90 layers, that hazard is the whole story.

3. mHC — Constrain the Mixing to the Birkhoff Polytope

DeepSeek-V4's manifold-constrained hyper-connections keep the \(n = 4\) lanes and the learned mixing \(B_\ell\), but project \(B_\ell\) onto the set of doubly stochastic matrices (non-negative entries; every row and every column sums to 1) before use — via 20 iterations of Sinkhorn–Knopp, which alternately normalizes rows and columns and converges to the projection.

Why doubly stochastic ⇒ no compounding

A doubly stochastic \(B\) has \(\lVert B \rVert_1 = 1\) (columns sum to 1) and \(\lVert B \rVert_\infty = 1\) (rows sum to 1), so by interpolation \(\lVert B \rVert_2 \le \sqrt{\lVert B \rVert_1 \lVert B \rVert_\infty} = 1\): the mixing can never amplify. And by Birkhoff–von Neumann, every such \(B\) is a convex combination of permutation matrices — the learned mixing is exactly a "soft shuffling" of lane contents. Mass is re-routed between lanes, never created; a product of 93 such matrices is still non-expansive. The identity path survives inside the constraint set (the identity is itself doubly stochastic), so the highway property is preserved, not sacrificed.

Sigmoid gates control each sublayer's read/write against the lanes. The mHC parameters are few but sensitive — V4 trains them with AdamW while the rest of the model runs Muon.

4. Attention Residuals — Read the Depth Axis Selectively

Kimi K3 keeps a single stream but replaces the uniform read with attention over depth: each layer forms a learned pseudo-query and takes a softmax-weighted combination of the (RMSNorm'd) outputs of preceding computation blocks. Layer 80 that needs layer 20's features specifically can put weight ~1 on them — dilution is gone, input-dependently, per token.

Full per-layer AttnRes at \(L = 93\) would add an \(O(L \cdot d)\) read per token per layer; K3's Block AttnRes partitions the 93 layers into 8 blocks of 12 and attends over block outputs (9 sources with the embedding), reducing the overhead to \(O(N \cdot d)\), \(N = 8\). The same structure then gets reused for free at serving time: K3's EAGLE-3 speculative drafter consumes exactly these low/mid/high block features (K3 page, §6).

5. One Idea, Two Costumes

The same constraint, spotted twice
mHC (DeepSeek-V4)

Mixing weights constrained doubly stochastic via Sinkhorn projection. Static per layer (learned parameters), input-independent. Flexibility axis: width — 4 lanes.

Block AttnRes (Kimi K3)

Read weights constrained non-negative-sum-to-1 via softmax. Dynamic — input-dependent per token. Flexibility axis: depth — 8 block sources.

Strip the branding and both designs make the identical move: replace uniform accumulation with a learned convex combination. Softmax outputs and doubly stochastic rows are both points in a probability simplex — non-negative weights summing to one — and that is precisely the constraint class that re-routes signal without amplifying it (§1's plot). Where they differ is which axis gets the flexibility (lanes vs. depth) and whether the weights see the data (static vs. per-token). It is the residual-stream version of a pattern this series keeps meeting: when you make a structural component learnable, you must simultaneously constrain it to conserve — compare routing bias updates that preserve top-\(k\) counts, or the gates in Gated DeltaNet bounded in \((0,1)\).

6. Why This Happened Now

  • Depth got extreme. At 93 layers, \(1/L\) dilution and single-lane superposition are far more binding than at GPT-2's 12. The deeper the stack, the more an addressable depth axis is worth.
  • The rest of the block ran dry. Attention and FFN have absorbed a decade of optimization; the residual stream was the last untouched component with structural slack.
  • Both labs bundle it with efficiency claims. Neither ships it as decoration: K3 counts AttnRes among the sources of its ≈2.5× scaling-efficiency gain over K2; V4 lists mHC among its core architectural bets. Independent adoption in the same generation is the strongest signal in architecture research — the same signal that blessed the 3:1 hybrid ratio.

7. Summary

The defect

Uniform accumulation: fixed weight-1 writes, undifferentiated reads, \(1/L\) dilution, one lane.

The hazard

Naively learned mixing compounds: gain \(1 \pm \epsilon\) per layer → \(e^{\pm \epsilon L}\) at depth \(L\).

mHC

4 lanes; mixing Sinkhorn-projected onto doubly stochastic matrices — soft permutations, \(\lVert B \rVert_2 \le 1\).

Block AttnRes

Softmax pseudo-query reads over 8 depth-blocks — input-dependent, \(O(Nd)\), reused by the EAGLE drafter.

The shared idea

Learned convex combinations replace uniform sums: re-route mass, never create it.

Status

Two independent frontier deployments in one generation — the block's next contested component.
