Gated DeltaNet

Linear attention that overwrites instead of accumulates — the delta rule as a targeted memory write, a learned forgetting gate on top, and how Qwen3-Next assembles it into its main token mixer.

The Basic Idea

Linear attention compresses the whole history into a fixed-size associative memory \(S\), but its write operation is blind: every token adds \(k_t v_t^\top\) on top of whatever is already stored. Nothing is ever corrected or removed — the memory just gets noisier.

DeltaNet replaces the blind write with a read–then–correct write:

  1. Read what the memory currently predicts for this key: \(\hat{v}_t = S_{t-1}^\top k_t\).
  2. Compare with the value we want stored: the error \(v_t - \hat{v}_t\).
  3. Write only the correction, scaled by a learned write-strength \(\beta_t \in (0,1)\).

If the key is new, the correction is (almost) the full value — a normal write. If the key was seen before, the write replaces the stale association rather than superimposing a second copy onto it. This is the delta rule — Widrow & Hoff's 1960 online learning rule — reborn as a memory controller: the state is a tiny linear model, and the sequence trains it by SGD as it streams past. "Gated" adds one more instrument: a per-token decay \(\alpha_t\) that lets the model deliberately forget. Qwen3-Next uses this combination — Gated DeltaNet (Yang et al., 2024) — as the token mixer in 3 out of every 4 layers.

1. The Delta Rule — Overwrite, Don't Accumulate

Step A — Read, compare, write the residual
\[ \hat{v}_t = S_{t-1}^\top k_t, \qquad S_t = S_{t-1} + \beta_t\, k_t\, (v_t - \hat{v}_t)^\top \]
Step B — The same update, rearranged

Substituting \(\hat{v}_t\) back in and factoring \(S_{t-1}\) out:

\[ S_t = \bigl(I - \beta_t\, k_t k_t^\top\bigr)\, S_{t-1} + \beta_t\, k_t v_t^\top \]

Read right to left: erase the \(k_t\)-component of the old memory (partially, by \(\beta_t\)), then write \(v_t\) in its place. At \(\beta_t = 1\) the erase term \(I - k_t k_t^\top\) is a projection that removes everything stored under \(k_t\) exactly.

Step C — Why the just-written association is exact

Because keys are unit-norm, reading back the key we just wrote gives

\[ S_t^\top k_t = \hat{v}_t + \beta_t (v_t - \hat{v}_t)\underbrace{(k_t^\top k_t)}_{=\,1} = (1-\beta_t)\,\hat{v}_t + \beta_t\, v_t , \]

a clean interpolation: \(\beta_t = 0\) keeps the old association, \(\beta_t = 1\) replaces it exactly. \(\beta_t\) is literally a learning rate — the update is one SGD step on \(\tfrac{1}{2}\lVert S^\top k_t - v_t \rVert^2\).

Side by side — the write operation
Vanilla linear attention — accumulate
\[ S_t = S_{t-1} + k_t v_t^\top \]

Re-writing a key stacks a second copy onto the first; retrieval returns their superposition.

DeltaNet — overwrite
\[ S_t = (I - \beta_t k_t k_t^\top) S_{t-1} + \beta_t k_t v_t^\top \]

Re-writing a key first clears what it pointed to; retrieval returns the new value.

delta rule, β = 1 delta rule, β = 0.5 additive write

The delta rule writes exactly; additive writes land in a haze. Simulated live in this page: random unit key/value pairs stream into a \(64 \times 64\) state, and after each write we measure the cosine similarity between the retrieval \(S^\top k_t\) and the value \(v_t\) that was just written (averaged over 8 runs). With \(\beta = 1\) the delta rule retrieves it perfectly at any load — the erase-then-write is exact for unit keys — while the additive write can't even store cleanly into its own memory once other items crowd it. Smaller \(\beta\) interpolates. The exactness isn't free: an aggressive write also damages old items sharing the key direction, which is why the decay gate below (and a recency-biased objective like language modeling) completes the picture.

2. The Gate — Learned Forgetting

The delta rule corrects what it re-reads, but associations that are never touched again just sit there forever. Gated DeltaNet adds a Mamba-2-style decay in front of the write:

Result — the Gated DeltaNet update
\[ S_t = \alpha_t \bigl(I - \beta_t\, k_t k_t^\top\bigr) S_{t-1} + \beta_t\, k_t v_t^\top, \qquad o_t = S_t^\top q_t \]

Both control scalars are computed per head, per token, from the layer input (via the small projection in_proj_ba):

  • Write strength \(\beta_t = \sigma(b_t)\) — how hard to commit this token's association into memory.
  • Decay \(\alpha_t = e^{g_t}\) with \(g_t = -e^{A^{\log}} \cdot \mathrm{softplus}(a_t + \Delta_{\text{bias}}) \,<\, 0\), so \(\alpha_t \in (0,1)\). The learned per-head parameters \(A^{\log}\) and \(\Delta_{\text{bias}}\) set a base forgetting timescale (the Mamba discretization, inherited notation and all), and the input-dependent \(a_t\) modulates it: the model can hold \(\alpha_t \approx 1\) through content it needs and slam the state toward zero at a topic boundary.

3. The Code

The reference decode path from Hugging Face transformers (torch_recurrent_gated_delta_rule in modeling_qwen3_next.py), trimmed to its loop — each line maps onto the math above: 

query = l2norm(query, dim=-1)              # unit-norm q, k  (Step C relies on this)
key   = l2norm(key,   dim=-1)
query = query * scale                      # 1/sqrt(d_k)

S = initial_state                          # (batch, heads, d_k, d_v)
for i in range(sequence_length):
    q_t, k_t, v_t = query[:, :, i], key[:, :, i], value[:, :, i]
    g_t    = g[:, :, i].exp()              # decay      alpha_t = e^{g_t}
    beta_t = beta[:, :, i]                 # write strength

    S = S * g_t                            # forget:  alpha_t * S
    v_hat = (S * k_t.unsqueeze(-1)).sum(-2)        # read:    S^T k_t
    delta = (v_t - v_hat) * beta_t                 # error:   beta_t (v_t - v_hat)
    S = S + k_t.unsqueeze(-1) * delta.unsqueeze(-2)  # write: + beta_t k_t (v_t - v_hat)^T

    o[:, :, i] = (S * q_t.unsqueeze(-1)).sum(-2)   # readout: S^T q_t

This loop is the semantics; it is only used when the fused kernels are missing. In production the sequential form runs one step per decoded token, and prefill/training use chunk_gated_delta_rule — the chunked form that processes the sequence in blocks of 64 with dense matmuls inside each block and this recurrence carried between blocks. Both come from flash-linear-attention (fla), which supplies Triton kernels for the chunked and recurrent forms across most of the modern linear-attention and SSM architectures. Two 2026 production stacks have since re-implemented the chunked form to beat FLA's Triton path: Moonshot's FlashKDA (CUTLASS, for KDA) and Qwen's FlashQLA (TileLang), which reports a 2–3× forward and ≈2× backward speedup over FLA on NVIDIA GPUs. The chunkwise algorithm itself — including the WY trick that chunk-parallelizes this delta rule — is derived on the chunkwise kernel page.

The fallback is silent. fla and causal-conv1d (§4) are optional installs. When they are absent the model does not raise — it quietly takes the eager path above and runs the recurrence as a Python loop over the sequence, which is orders of magnitude slower than the chunked kernel and produces the same numbers. So the failure has no error message and no wrong output: it shows up only as an unexplained slowdown, and in a profile as an enormous count of small elementwise ops where a handful of fused kernels should be. Worth an explicit startup assertion that the fused path actually engaged — the cost of checking is far below the cost of discovering it later.

4. Inside Qwen3-Next

The full Qwen3NextGatedDeltaNet layer wraps the recurrence with four pieces:

The layer, end to end

input → in_proj_qkvz + in_proj_ba → causal conv1d (silu) over q,k,v → gated delta rule → per-head RMSNorm ⊙ silu(z) → out_proj

Qwen3.8-Next (report, §2.1.1) changes the last step to a bounded sigmoid gate, \(o_t = W_o\bigl[\sigma(W_z x_t) \odot \mathrm{RMSNorm}(y_t)\bigr]\), and reports consistent gains over SiLU across its experiments — the same swap Kimi K3 made on its KDA and MLA layers, and the same preference for bounded gates its residual ablation found. It also uses zero-centered RMSNorm for every norm in the layer, inherited from Qwen3-Next.
  • One projection, six outputs. in_proj_qkvz produces \(q, k, v\) and the output gate \(z\) in a single matmul; in_proj_ba produces the two control scalars \(b_t, a_t\) per value head. None of the controls pass through the recurrence — they are direct functions of the current token.
  • A short causal conv1d (kernel size 4, depthwise, silu) runs over \(q, k, v\) before the recurrence. The delta rule is a pure key–value mechanism with no notion of adjacency; the convolution supplies cheap local n-gram mixing so the recurrent state can spend its capacity on longer-range content. In practice this is its own hand-written kernel — causal-conv1d, shared with Mamba — rather than a torch.nn.Conv1d. Every constraint here is a specialization a general convolution cannot exploit: depthwise means no cross-channel reduction, so it is bandwidth-bound rather than compute-bound; causal makes the left pad implicit; widths of 2–4 unroll completely; and the silu is fused rather than costing a second pass over memory.
  • Head layout: 32 value heads of dimension 128 share 16 key/query heads (each \(q, k\) pair serves two value heads), giving each head a \(128 \times 128\) state — about 0.5M fp32 floats per layer per sequence, constant in context length.
  • The hybrid stack: layers repeat the pattern DeltaNet, DeltaNet, DeltaNet, full attention (48 layers → 12 softmax-attention layers in the 80B-A3B config). The few full-attention layers provide exact unbounded recall; the DeltaNet layers carry the bulk of the sequence modeling at \(O(1)\) per-token cost — the general pattern is on the hybrid attention page.
Terminology bridge: Mamba-2 papers write the state update in SSM notation (\(h_t = A_t h_{t-1} + B_t x_t\)); Gated DeltaNet is the same object with \(A_t = \alpha_t (I - \beta_t k_t k_t^\top)\) — a decay times a (generalized) Householder transform — instead of a diagonal. The "linear attention ↔ SSM" duality of Mamba-2 is what makes the chunked kernel possible here too.

5. Summary

Update

\(S_t = \alpha_t (I - \beta_t k_t k_t^\top) S_{t-1} + \beta_t k_t v_t^\top\)

Delta rule

Write \(\beta_t(v_t - \hat{v}_t)\): replace stale associations instead of stacking onto them

Gate

\(\alpha_t = e^{g_t}\): input-dependent forgetting, per head, Mamba-style parameterization

In Qwen3-Next

3 of every 4 layers; conv1d in front, gated RMSNorm behind, hybrid with full attention
