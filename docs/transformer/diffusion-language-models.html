Diffusion Language Models

Replace next-token prediction with repeated categorical denoising. Parallel updates change the generation order—not the need to model dependencies.

Reading path: diffusion fundamentals → this page → DiffusionGemma. Compare with autoregressive pretraining: ordinary next-token training is already parallel under teacher forcing; it is generation that waits for each newly sampled token.

1. Corrupt categories, not token ID numbers

For a clean token \(x_i\), let \(z_{t,i}\) be a noisy token at time \(t\in[0,1]\). Write \(a(t)\) for the probability of retaining the clean token, decreasing from one to zero. A useful family of categorical corruption marginals is:

\[ q(z_{t,i}=v\mid x_i)=a(t)\,\mathbf 1[v=x_i]+(1-a(t))\,\pi(v). \]

The notation \(a(t)\) is a retention probability, not the Gaussian noise amplitude from the previous page. The distribution \(\pi\) determines what "noise" means:

CorruptionNoise distributionWhat the denoiser sees
Absorbing / maskedAll mass on a special [MASK] symbolVisible clean tokens and explicitly missing positions.
Uniform stateUniform over the token vocabularyA mixture of clean and random tokens, without a reliable marker identifying noise.

A uniformly replaced token can coincidentally equal the original. Corruption is not the same as "choose a different word." Neither process adds a Gaussian to an integer ID or assumes nearby vocabulary IDs have related meanings. Continuous-embedding diffusion is a separate design family.

2. Denoising targets stay at the same position

A transformer takes the entire corrupted sequence, optional noise-level information, and any fixed prompt \(c\). It predicts a clean-token distribution \(p_{\theta,i}(v\mid z_t,c,t)\) at each output position. The target is \(x_i\), not the shifted next token \(x_{i+1}\). Bidirectional attention over the noisy output is valid: it can inspect other noisy or visible positions, but must not receive a hidden position's clean target through a separate input path.

For the absorbing-state MDLM parameterization, visible tokens are carried over and the predicted clean distribution assigns no probability to [MASK]. The continuous-time negative evidence lower bound reduces to a weighted masked cross-entropy objective:

\[ \mathcal L_{\mathrm{MDLM}} =\mathbb E_{x,\,t\sim U(0,1),\,z_t} \left[ \frac{-a'(t)}{1-a(t)} \sum_i \mathbf 1[z_{t,i}=\mathrm{MASK}] \big(-\log p_{\theta,i}(x_i\mid z_t,t)\big) \right]. \]

This form uses the ideal clean/noise endpoint limits and the MDLM carry-over parameterization. Endpoint truncation or another corruption law changes the details. With \(a(t)=1-t\), the positive weight is \(1/t\): rare masked positions at small \(t\) receive more weight. It is not a recipe to set \(t=0\) and divide by zero.

Pseudocode for the interior denoising term, with a deliberately truncated \(t\in[\varepsilon,1]\) for numerical safety:

x, valid = sample_token_batch()
t = sample_uniform(epsilon, 1, per_example=True)
masked = (uniform_like(x) < t[:, None]) & valid
zt = where(masked, MASK_ID, x)
logits = denoiser(zt, t, attention_mask=valid)
logits[..., MASK_ID] = -infinity
ce = cross_entropy_per_position(logits, x)
per_example = sum(ce * masked, axis=-1) / t
loss = (1 - epsilon) * mean(per_example)
update_parameters(loss)

The factor \(1-\varepsilon\) estimates the integral over that truncated interval; this snippet omits the remaining endpoint treatment and is not an exact full-likelihood implementation. Normalize per token instead of per sequence if that is the declared training convention. Do not silently replace the sum by a mean over just the sampled masks: that changes the timestep weighting. A sample with no masked positions has zero contribution, not a division by zero. Padding is excluded; for conditional response training, keep the prompt fixed and define a separate response-loss mask.

This is one derivation, not every diffusion LM's loss. Uniform-state diffusion has a different reverse process and likelihood objective. The masked-only indicator and MDLM carry-over rule should not be copied into a uniform-token model such as DiffusionGemma.

3. Parallel predictions still need a sampling rule

In basic masked diffusion, initialize output positions as masks. At reverse times \(s<t\), a currently masked position becomes unmasked with probability

\[ u(s,t)=\frac{a(s)-a(t)}{1-a(t)}. \]

If selected, sample a clean token from the denoiser's categorical distribution; otherwise leave a mask. With \(a(t)=1-t\), this becomes \((t-s)/t\). Already unmasked tokens are unchanged in the basic absorbing reverse chain. At the final step \(s=0\), all remaining masks are filled.

The network shares context across positions, but sampling a large set from separate per-position distributions in one pass does not reproduce all their joint dependencies. Subsequent passes can condition on newly available tokens. Confidence-ranked unmasking, remasking, and other accelerated schedules are additional sampler choices—not an automatic consequence of the equation above or guarantees of exact sampling.

Revision is possible, not guaranteed correct

A monotone absorbing sampler cannot revise committed words. A sampler can introduce remasking, while uniform-state methods naturally allow repeated replacement. Either way, low entropy means the model is confident, not that an external verifier has proved a token correct. Denoising may stabilize at a wrong answer.

4. Full-sequence versus block-autoregressive generation

A full-sequence diffusion model denoises a chosen-length output canvas. A block-autoregressive design denoises a block of \(B\) tokens, commits it, then generates the next block conditioned on earlier completed blocks:

\[ p_\theta(x\mid c)=\prod_b p_\theta(x^{(b)}\mid c,x^{(<b)}). \]

Each block conditional is itself implemented by a denoising process. Thus the system is bidirectional within the active block and autoregressive between blocks. Committed earlier blocks are not automatically editable. Output length, end-of-sequence detection, partial final blocks, and streaming are explicit implementation choices.

5. Fewer sequential passes does not imply proportional speedup

Let \(L\) be output length, \(K_b\) the denoising passes for block \(b\), \(t_d(B)\) a block denoiser's latency, and \(t_e(B)\) its context-encoding cost. A simplified generation budget is:

\[ T_{\mathrm{diff}}\approx T_{\mathrm{prompt}}+ \sum_{b=1}^{\lceil L/B\rceil} [K_b\,t_d(B)+t_e(B)+t_{\mathrm{sampler},b}]. \] \[ T_{\mathrm{AR}}\approx T_{\mathrm{prompt,AR}}+ L\,t_{\mathrm{token}}. \]

Costs also depend on the growing context and request batch size; constants here are local approximations. More parallel positions can use otherwise idle GPU compute at low concurrency, but repeatedly processing them also costs FLOPs and memory traffic. At high concurrency, autoregressive batching can already exploit that compute.

6. Not BERT, not multi-token prediction, not speculative decoding

MethodKey distinction
Classical masked language modelingA corruption-and-reconstruction pretraining task. It does not, by itself, specify a noise-indexed generative chain and its likelihood bound.
Multi-token predictionAdds future-token training targets or draft heads to an autoregressive model; it need not define any corruption process.
Diffusion language modelA learned generative distribution sampled by categorical denoising. There is no requirement that it match a separate autoregressive model.
Exact speculative decodingA drafter proposes tokens and a target verifies them with the appropriate correction to preserve the target distribution. The drafter itself may be diffusion-based.

Likewise, summing a denoiser's per-position log-probabilities from a single pass does not generally give the generated sequence's marginal log-likelihood. Diffusion likelihood bounds and autoregressive exact likelihoods must be labeled distinctly when reporting perplexity.
