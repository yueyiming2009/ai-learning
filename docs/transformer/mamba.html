Mamba & State Space Models

The other road to a fixed-size sequence state: continuous-time state spaces, the discretization step that turns \(\Delta\) into a forgetting knob, the selection mechanism that made SSMs content-aware, and the Mamba-2 restriction that reunited them with linear attention — and filled forty of Nemotron 3's forty-eight token mixers.

The linear attention page reaches a fixed-size recurrent state by deleting the softmax from attention. This page reaches the same object from the opposite direction — control theory's state space model, discretized, made selective, and engineered onto GPUs. The two derivations converged in 2024 (Mamba-2's "state space duality"), and the converged object is now production infrastructure: Nemotron 3 runs 40 of its 48 token mixers as Mamba-2 layers, and Jamba, Nemotron-H, and the 3.5-generation Lightning all build on the same layer. The attention-side pages treat Mamba-2 as "the diagonal-decay rung of the ladder"; here we build it natively, so that every key in its config.json — ssm_state_size, n_groups, conv_kernel — has a place to come from.

1. The State Space — a Signal Processor's RNN

A (linear, single-input) state space model couples a scalar input signal \(x(t)\) to a scalar output \(y(t)\) through an \(N\)-dimensional latent state \(h(t)\):

\[ h'(t) = A\,h(t) + B\,x(t), \qquad y(t) = C\,h(t) \]

with \(A \in \mathbb{R}^{N\times N}\), \(B \in \mathbb{R}^{N\times 1}\), \(C \in \mathbb{R}^{1\times N}\). This is the workhorse of classical control and signal processing: the state integrates the input's history, \(A\) governs how that memory evolves (and decays), and \(C\) reads out whatever combination the output needs. Used as a deep learning layer, one such SSM is attached to each channel of a \(d\)-dimensional residual stream — \(d\) independent little integrators of size \(N\) (S4 used \(N = 16\)), stacked and interleaved with the usual mixing machinery.

Two things stand between this object and a working token mixer: tokens are discrete, so the differential equation must be discretized (§2), and the dynamics \((A, B, C)\) are fixed for all time — the model processes every token identically, a limitation that takes the whole S4 era (§3) to feel and Mamba (§4) to fix.

2. Discretization — \(\Delta\) Is the Forgetting Knob

To step the continuous system token by token, pick a step size \(\Delta\) and integrate over one step. Holding the input constant across the step (the zero-order hold) gives an exact recurrence:

\[ h_t = \bar A\,h_{t-1} + \bar B\,x_t, \qquad \bar A = e^{\Delta A}, \quad \bar B = (\Delta A)^{-1}\!\left(e^{\Delta A} - I\right)\Delta B \;\approx\; \Delta B \]

(Mamba uses the simple Euler approximation \(\bar B = \Delta B\); the exact ZOH factor rarely matters.) With \(A\) diagonal and negative — say a single eigenvalue \(-a\), \(a > 0\) — the state transition is just a decay factor \(\bar\alpha = e^{-\Delta a} \in (0,1)\), applied every step. The content of the state therefore survives \(k\) steps with weight \(\bar\alpha^k = e^{-a\Delta k}\), and \(\Delta\) is revealed as something much more interesting than an integration step: it is a forgetting timescale, with half-life \(\ln 2 / (a\Delta)\) steps.

\(\Delta = 0.05\) \(\Delta = 0.2\) \(\Delta = 1\) \(\Delta = 4\)

One knob spans "remember for pages" to "reset now." Retention \(e^{-a\Delta k}\) of state content after \(k\) steps, for four values of \(\Delta\) (\(a = 1\)). At \(\Delta = 0.05\) the half-life is ~14 tokens and content survives the whole window; at \(\Delta = 4\) the state is erased within a single step — and because \(\bar B \approx \Delta B\), the same large \(\Delta\) that erases also writes the current input hard. Small \(\Delta\) = ignore this token; large \(\Delta\) = reset on it.

Note the coupling: \(\Delta\) scales both the decay in \(\bar A\) and the write strength in \(\bar B\). A large step forgets the past and commits to the present; a tiny step preserves the past and barely registers the input. One scalar interpolates between "skip this token" and "restart from this token" — remember this, because making that scalar input-dependent is the entire Mamba insight.

3. S4 — Long Memory Without Selection

The first wave (S4, 2021) attacked a different problem: initialization. A randomly initialized \(A\) forgets exponentially fast in a useless way. The HiPPO theory chooses \(A\) so that the state \(h(t)\) maintains an optimal projection of the entire input history onto a polynomial basis — a principled long memory, and the reason S4 crushed long-range-dependency benchmarks that transformers of the day failed. S4's technical machinery (diagonal-plus-low-rank \(A\), later simplified to purely diagonal in S4D) exists to make this choice computable; the modern takeaway is just: diagonal \(A\), carefully initialized, works.

Because \((A, B, C, \Delta)\) are constants, the system is linear time-invariant, and LTI systems have a second computational form. Unrolling the recurrence:

\[ y = x * \bar K, \qquad \bar K = \left(C\bar B,\; C\bar A\bar B,\; C\bar A^2\bar B,\; \dots\right) \]

— the whole layer is a convolution with a kernel as long as the sequence, computable via FFT in \(O(L \log L)\) with no sequential scan at all. Training parallelism came free; this is what made the S4 era viable on GPUs.

But time-invariance is also the ceiling. A fixed kernel weights history by position only — every token is written with the same strength and forgotten at the same rate, whether it's a key fact or filler. On synthetic probes of content-based manipulation (selective copying, induction heads), LTI SSMs fail outright: the model cannot decide what to remember, only how far back to remember. This is precisely the fixed-decay limitation of the RetNet rung on the linear-attention fix ladder — the same wall, hit from the other side.

4. Mamba — Selection Breaks the Convolution, the Scan Saves It

Mamba's move (2023) is one sentence: make the SSM parameters functions of the current token,

\[ \Delta_t = \mathrm{softplus}(W_\Delta x_t + b_\Delta), \qquad B_t = W_B x_t, \qquad C_t = W_C x_t \]

while \(A = -\mathrm{diag}(e^{a_{\log}})\) stays a learned constant that the input reaches only through \(\Delta_t\). Now the forgetting knob of §2 is content-aware: the model reads a token and decides, per channel, whether this is a keep-the-state moment (\(\Delta_t \to 0\)) or a write-and-reset moment (\(\Delta_t\) large). The connection to classical gates is exact, not analogical: since \(e^{-\mathrm{softplus}(z)} = \sigma(-z) = 1 - \sigma(z)\), the discretized transition is a sigmoid forget gate — the selective SSM contains the gated RNN as the \(N = 1\) special case.

LTI: fixed \(\bar\alpha = e^{-0.08}\) every step selective: \(\Delta_t \approx 0\) on filler, spike at the break

Selection is content-aware forgetting. Both layers store a token at step 0; the curves show how much of it survives. The LTI layer must decay at one fixed rate — by step 30 the memory is mostly gone whether or not anything needed to replace it. The selective layer sets \(\Delta_t \approx 0\) across 39 filler tokens (per-step retention \(\approx 0.998\)), holds the memory nearly lossless, then spikes \(\Delta_t\) at the context break at step 40 — erasing and rewriting exactly when the content says to.

The price is structural: with \(\bar A_t\) varying per token the system is no longer LTI, the convolutional form of §3 is gone, and the recurrence must actually be computed in sequence. Mamba's second contribution is making that affordable — the hardware-aware selective scan:

  • the recurrence \(h_t = \bar\alpha_t h_{t-1} + \bar B_t x_t\) is associative, so a work-efficient parallel scan computes all \(L\) states in \(O(L)\) work and \(O(\log L)\) depth rather than \(L\) sequential steps;
  • discretization, scan, and output projection are fused into one kernel that keeps the expanded state in SRAM — the \((L, d, N)\) tensor of states is never materialized in HBM, and is recomputed in the backward pass instead of stored.

Around the SSM, Mamba wraps a block: expand the residual stream \(d \to 2d\), run a short causal conv1d (kernel 4) over the SSM branch to give each position a peek at its immediate neighbors, apply SiLU, run the selective SSM, and gate the result with a second SiLU branch before projecting back down. That width-4 convolution is the direct ancestor of the conv_kernel: 4 in every Nemotron config.

5. Mamba-2 — Restrict the Transition, Win Back the Matmul

The selective scan is elementwise work — no matrix multiplies — so Mamba-1 leaves tensor cores idle. Mamba-2 (2024) buys them back with one restriction: within each head, collapse the per-channel diagonal decay to a single scalar, \(\bar A_t = \alpha_t I\) with \(\alpha_t = e^{-\Delta_t a}\). Group the channels into heads of dim \(P\), keep a state matrix \(S_t \in \mathbb{R}^{N \times P}\) per head, and the recurrence becomes an outer-product update:

\[ S_t = \alpha_t\,S_{t-1} + B_t X_t^{\top}, \qquad Y_t = C_t^{\top} S_t \]

Squint at the roles: \(B_t\) decides where in the state to write — a key. \(C_t\) decides what the output reads — a query. \(X_t\) is the content — a value. This is precisely gated linear attention, \(S_t = \alpha_t S_{t-1} + k_t v_t^{\top}\), derived from the SSM side. Mamba-2's state space duality makes the identification exact: unrolled, the layer computes

\[ Y = (L \circ C B^{\top})\,X, \qquad L_{ij} = \alpha_{j+1}\alpha_{j+2}\cdots\alpha_i \;\;(i \ge j) \]

— "attention" whose causal mask \(L\) is a matrix of cumulative decay products (1-semiseparable, in the paper's language) instead of softmax normalization. One object, two computational forms: run it as a recurrence for \(O(1)\) decode, or in chunks — attention-like matmuls within each 64-token chunk, a single state handoff between chunks — for tensor-core-saturating training. The chunkwise kernel page derives that algorithm in full; it is the same one FLA ships for GLA, Gated DeltaNet, and KDA.

The restriction is what the duality costs: per-channel decay (GLA's \(\mathrm{Diag}(\alpha_t)\), KDA's fine-grained gate) breaks the clean semiseparable form and needs the costlier secondary-chunking kernel. Mamba-2 takes the coarser scalar-per-head gate and, in exchange, scales the state up almost for free: with the matmul form, \(N\) jumps from S4's 16 to 128, an 8× bigger memory per channel at similar speed.

6. The Layer, Decoded

Everything above compiles down to five config keys. Reading them off Nemotron 3 Super's config.json:

Config keySuper valueWhat it is
mamba_num_heads128heads \(H\); with head dim 64 the inner width is \(128 \times 64 = 8192 = 2\times\) hidden — Mamba's classic ×2 expansion
mamba_head_dim64\(P\), channels per head sharing one scalar gate \(\alpha_t\)
ssm_state_size128\(N\), state rows per head — the Mamba-2 dividend over S4's 16
n_groups8heads per \(B_t, C_t\) pair — GQA's key/value-head sharing, transplanted to SSMs (16 heads share each group's projections)
conv_kernel4the short causal conv from the Mamba block (§4); at decode it adds only a 3-token input buffer

The output path is the gated-RMSNorm arrangement covered on the gated normalization page: SiLU gate branch, multiply, normalize, project back to the residual stream.

The hybrid economics, in one number

Per-layer state: \(H \times N \times P = 128 \times 128 \times 64 \approx 1\text{M}\) elements — ≈ 2 MB in BF16, constant at any context length. Nemotron's GQA layers cache 512 elements (1 KB) per token, so a Mamba layer's entire memory equals just 2,048 tokens of attention cache; at 1M context each attention layer holds ≈ 1 GB per sequence while each Mamba layer still holds 2 MB. That three-orders-of-magnitude gap at long context is the entire case for hybrid stacks — and why NVIDIA rations attention to 8 layers in 88.

7. One Object, Two Derivations

The reunion
From attention (the linear-attention page)

Delete the softmax → attention becomes \(S_t = S_{t-1} + k_t v_t^{\top}\) → add a decay gate to stop the state from saturating → \(S_t = \alpha_t S_{t-1} + k_t v_t^{\top}\).

From control theory (this page)

Discretize a state space → \(\Delta\) becomes a forgetting gate → make it selective → restrict the transition to a scalar per head → \(S_t = \alpha_t S_{t-1} + B_t X_t^{\top}\).

Same equation, and the family tree on the KDA page files everything by what multiplies \(S_{t-1}\): Mamba-2's decay-only transition, DeltaNet's Householder erase-write, Gated DeltaNet's scalar-decay × Householder, KDA's diagonal × Householder. One precision worth carrying: within a head, Mamba-2's decay is a single shared scalar — the per-channel \(\mathrm{Diag}(\alpha_t)\) refinement is GLA and KDA territory, and it costs the cleaner kernel. What decay-only genuinely gives up is the delta rule's targeted erase: Mamba-2 can only fade the whole head's memory uniformly, never overwrite one association while keeping its neighbors — the capacity argument the Gated DeltaNet page makes with a live simulation.

Deployment-wise the lineage runs Jamba (2024, first production Mamba hybrid) → Nemotron-H (2025, Mamba-2 at 8:1) → Nemotron 3 / 3.5 (2026, 5:1 and ~4:1, no positional embeddings anywhere). NVIDIA's bet, twice restated at frontier scale, is that with a capable attention layer every ~5 slots, the cheapest linear mixer — pure decay, no Householder — is enough. The competing bets (Qwen's Gated DeltaNet, Kimi's KDA) pay more per linear layer for stronger in-state recall; the hybrid attention page covers the ratio economics that frame all three.

8. Summary

The object

\(h_t = \bar A h_{t-1} + \bar B x_t\): a control-theory state space, discretized into an RNN with structured, decaying memory.

Δ is the gate

Discretization turns the step size into a forgetting timescale: \(e^{-\mathrm{softplus}} = \sigma(-\cdot)\) — the sigmoid forget gate, rederived.

S4 → Mamba

LTI SSMs = convolutions: parallel but content-blind. Selection (\(\Delta_t, B_t, C_t\) from the token) fixes recall, kills the convolution, and demands a fused parallel scan.

Mamba-2 / SSD

Scalar-per-head decay makes the layer gated linear attention exactly — semiseparable mask, chunkwise matmul training, state 8× bigger.

The layer, keyed

heads × head-dim = 2× hidden; \(N = 128\); n_groups = GQA for SSMs; conv_kernel 4 — every Nemotron config key decoded.

The trade

≈2 MB of state per layer at any context vs ≈1 GB/layer for attention at 1M — bought by giving up targeted erase and exact recall.
