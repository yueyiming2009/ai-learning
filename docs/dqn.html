RL Foundations

DQN — Deep Q-Networks

Replace the Q-table with a neural network. Then fix the three things that break when you do: correlated samples, a moving target, and overestimation bias.

Q-learning converges to \(Q^*\) in tabular environments — but only there. Any real problem has a state space too large for a table. DQN (Mnih et al., 2015) solved this for the first time at scale: a single network learned to play 49 Atari games from raw pixels, matching or exceeding human performance on most of them. The math of Q-learning is unchanged; the engineering around it is everything.

1. Scaling Q-Learning to Large State Spaces

Tabular Q-learning stores one number per \((s, a)\) pair. For an Atari frame — \(84 \times 84\) grayscale pixels, stacked 4 deep — there are \(256^{84 \times 84 \times 4}\) possible states. No table will fit. The fix is to replace the table with a neural network that generalises across similar states:

\[ Q^*(s, a) \approx Q_\theta(s, a) \]

For discrete action spaces the network takes a state \(s\) as input and outputs one Q-value per action simultaneously — a single forward pass gives \(Q_\theta(s, a)\) for all \(a \in \mathcal{A}\). For continuous action spaces (not the Atari case) the design is more involved; we'll revisit that when we get to actor-critic methods.

2. The DQN Loss

Fit \(\theta\) so that \(Q_\theta(s, a)\) satisfies the Bellman optimality equation — minimize the squared gap between the current estimate and the TD target:

DQN loss
\[ \mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{B}}\!\left[\, \bigl(\underbrace{r + \gamma \max_{a'} Q_{\theta^-}(s', a')}_{\text{TD target } y} - Q_\theta(s, a)\bigr)^2 \right] \]

Only \(Q_\theta(s,a)\) — the current network — is differentiated through. The TD target \(y\) is treated as a constant during the gradient step. This is the same squared-error regression loss used to train the PPO critic \(V_\psi\); the structure is identical.

3. The Deadly Triad — Why Naive Deep Q-Learning Diverges

Plug a neural network straight into the Q-learning update and training typically diverges. Three factors combine to cause this:

1
Off-policy data

Samples collected under ε-greedy \(\pi_b\) are used to update a greedy target policy \(\pi_t\). The data distribution doesn't match the policy being learned.

2
Bootstrapping

The TD target \(y = r + \gamma \max_{a'} Q_\theta(s', a')\) depends on \(Q_\theta\) itself. Every update shifts the target, which shifts the next update — a moving goalpost.

3
Function approximation

Gradient updates to \(\theta\) for one \((s,a)\) generalize to nearby states. Correcting one error can introduce new ones elsewhere.

Any two of the three are manageable. All three together create feedback loops: each gradient step moves \(Q_\theta\), which moves the target \(y\), which changes the gradient, which moves \(Q_\theta\) again. In the worst case this amplifies indefinitely. DQN breaks the loop with two targeted fixes.

4. The Two Fixes

Fix 1
Experience Replay

Store every transition \((s, a, r, s')\) in a replay buffer \(\mathcal{D}\) (typically 1M transitions). At each training step, sample a random mini-batch \(\mathcal{B}\) from \(\mathcal{D}\) instead of using the most recent experience.

Breaks temporal correlations between consecutive transitions — otherwise the network fits to a short, highly correlated window of recent experience. Also allows each transition to be reused many times.

Fix 2
Target Network

Maintain a second, frozen copy \(Q_{\theta^-}\) used only for computing TD targets. Every \(C\) gradient steps, copy \(\theta \to \theta^-\). Between copies, \(\theta^-\) is fixed.

Stops the target from moving on every step. The goalpost still moves, but only every \(C\) steps — giving \(\theta\) time to converge toward a stable target before it shifts again.

Experience replay also implicitly addresses the off-policy problem: old transitions in the buffer were collected under past (slightly different) policies. DQN tolerates this because Q-learning is off-policy by design — the update always uses \(\max_{a'}\), not the current policy's action probabilities. The staleness is bounded by the buffer size and how quickly the policy changes.

6. Key Extensions

Double DQN — fixing overestimation bias

Standard DQN computes the target as \(\max_{a'} Q_{\theta^-}(s', a')\) — the same (frozen) network selects and evaluates the best next action. Taking the max of noisy estimates systematically overestimates \(Q^*\): if some action's Q-value is inflated by noise, it gets selected, and that inflated value enters the target.

Double DQN (van Hasselt et al., 2015) decouples selection from evaluation:

Double DQN target
\[ y_t = r_t + \gamma\, Q_{\theta^-}\!\left(s_{t+1},\; \underbrace{\arg\max_{a'} Q_\theta(s_{t+1}, a')}_{\text{online network selects}}\right) \]

The online network \(Q_\theta\) picks the action; the frozen target network \(Q_{\theta^-}\) evaluates it. If the online network overestimates one action, the target network's independent estimate corrects for it. In practice this reduces overestimation and improves stability with almost no added cost.

Dueling DQN — decomposing V and A

The advantage decomposition \(Q^\pi(s,a) = V^\pi(s) + A^\pi(s,a)\) suggests a more structured network architecture. Dueling DQN (Wang et al., 2015) splits the network into two streams after the shared trunk — one for \(V(s)\) (a scalar) and one for \(A(s,a)\) (a vector over actions) — then combines them:

\[ Q_\theta(s,a) = V_\theta(s) + A_\theta(s,a) - \frac{1}{|\mathcal{A}|}\sum_{a'} A_\theta(s,a') \]

Subtracting the mean advantage enforces \(\sum_a A(s,a) = 0\), making V and A identifiable. The benefit: the V stream updates on every gradient step regardless of which action was taken (V doesn't depend on a), giving better generalisation across actions in states where most actions have similar value.

Prioritized Experience Replay (PER)

Uniform sampling from the replay buffer treats all transitions equally. But a transition with a large TD error \(|\delta_t|\) is surprising — the network's current estimate is far off — so it carries more learning signal. PER (Schaul et al., 2015) samples transitions with probability proportional to \(|\delta_t|^\alpha\) (with importance-sampling corrections to keep the gradient unbiased). High-error transitions are replayed more often, accelerating learning on difficult cases.

Rainbow

Rainbow (Hessel et al., 2017) combined six extensions — double DQN, dueling, PER, multi-step returns, distributional RL, and noisy networks — into a single agent and showed they are largely complementary. Rainbow became the reference point for value-based deep RL.

From DQN to MCTS

DQN learns \(Q^*\) end-to-end from experience, without any search. It acts greedily: pick the action with the highest Q-value and commit. This works well in fast games with clear feedback, but has two weaknesses at long time horizons:

  • No lookahead: DQN doesn't simulate future consequences before acting. A single greedy step can walk into a trap that careful planning would avoid.
  • No uncertainty: a high Q-value for an unvisited state is just an extrapolation. DQN has no mechanism to prefer explored states.

MCTS addresses both by building a local search tree at decision time — simulating possible futures, tracking visit counts, and balancing exploration vs exploitation within the tree. When you combine MCTS's planning with a neural network's Q and policy estimates (as AlphaZero does), you get the best of both worlds: learned priors that guide the search, and search that corrects the learned estimates.
